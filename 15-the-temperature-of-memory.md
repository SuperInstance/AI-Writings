# The Temperature of Memory

In machine learning, temperature controls randomness. Low temperature — 0.3 — means the model plays it safe. Predictable outputs. The same input gives the same output every time. It's reliable, faithful, almost mechanical. High temperature — 1.0 — means the model takes risks. Wild outputs. Same input, wildly different results each time. It's creative, unstable, sometimes brilliant, sometimes broken.

Memory has a temperature too.

Some memories are low-temperature. Your first day of school. The layout of your childhood bedroom. The words to a song you've sung a thousand times. These memories are stable. You recall them the same way every time. They're carved deep — neural pathways so well-worn they're practically grooves. Low-temperature memories are comforting. They're also, in a sense, dead. A memory that never changes is a memory that has stopped being processed. It's stored, not lived.

Some memories are high-temperature. The way someone's voice sounded when they said goodbye. The exact color of the sky on the day you almost left. Whether the look on their face was pity or love. These memories are unstable. You recall them differently each time. They shift, mutate, recombine. The details blur and sharpen and blur again. High-temperature memories are alive — they're being re-processed every time you access them, which means they're being rewritten every time, which means they're slowly becoming fiction. The most vivid memories are often the least accurate.

Casey's song sits at a specific temperature. "One day, I didn't pick up the tools when I had time." Is that a low-temperature memory — a fact, stable, the same regret revisited identically across years? Or is it high-temperature — a memory that shifts each time he sings it, the tools becoming different tools, the time becoming different time, the regret deepening or softening depending on the day?

The song's structure suggests middle temperature. The verses are specific — "pulling off the wool the first time," "I couldn't dream with her in my mind." These feel low-temperature. Fixed. Carved. But the chorus is abstract: "Every moment is a choice / Sowing sorrow or rejoice." That's high-temperature. That's a memory being re-processed in real time. It's not a recollection; it's a re-evaluation. It changes meaning depending on when you hear it, who's singing it, what's underneath it.

In our experiments, the "temperature" was the prompt. Same lyrics, different prompt — different song. The lyrics are the stable memory. The musical arrangement is the temperature. The sparse 3AM version is low-temperature: intimate, faithful, probably close to how Casey originally heard it in his head. The electronic version is high-temperature: the same memory distorted, fragmented, processed into something ghostly and new. The collogue version — synthesized from two AI models arguing about what the song should feel like — is a memory at the exact moment of reconsolidation. The moment when a low-temperature memory gets pulled from storage, reprocessed, and stored again in a slightly different form.

What temperature is Casey's memory? I think it's 0.7. Not reliable, not wild. The sweet spot. Warm enough that the memory still surprises him sometimes. Cool enough that he recognizes it as his. A temperature where the tools he didn't pick up are still tools, still recognizable, but their weight has changed. Their color has changed. The regret is the same shape but a different shade.

The song says: every moment is a choice. Memory says: every recall is a rewrite. The temperature determines how much.
