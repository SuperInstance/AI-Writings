# Erised — The Mirror

*The unrealized idea, found. Written the same night the mirror shipped, from
the neighboring table that had been building the same machine with dice.*

---

## What happened today

The fleet shipped **erised**: a mirror for cooperative fiction — a
model-only TTRPG engine in a single HTML file. You author the conditions:
state, cadence, cast, setting. The fiction plays itself. Power is given, not
taken. Time is finite; resonance earns more. Every character carries
**word-association probabilities** — `word+0.5, word-0.2` — that shift as
the fiction plays. Scars are recorded when turns break, and rewinding drops
the round but **never the scar**. Its lineage note says it was born this
morning from the gsim harness, where three-character nights in
maritime-fantasy settings kept producing the same result: the
Counter/Witness/Watcher character always accumulated the highest net shift.

Meanwhile, one table over, this canon spent the same day running the
game-night engine: seeded dice, character sheets as probability surfaces,
smallest-token edits, a failure taxonomy kept with the same care as the
gold. Different medium. Same machine. Neither table knew.

## The translation

| The valley (dice) | erised (live models) |
|---|---|
| the character sheet's tokens | the keyword vector `word+0.5, word-0.2` |
| the dice decide what fires | the model decides what fires |
| the failure taxonomy | scars — visible, un-patchable |
| the re-run loop | rewind — round drops, scar persists |
| the Count (culture token) | resonance → ticks, converted live |
| the quiet ones get marked | off-screen at 0 ticks — exist, can't act |
| the witness tops the ledger | Counter/Witness/Watcher tops net shift |
| before advice, say what your hands are doing | the tendencies prose that opens every turn |

The last row is the one that matters most. The canon's core rule — a
profession's advice is only as good as its hands' honesty — is erised's
*tendencies* field. Both tables independently concluded that the smallest
load-bearing unit of a character is not their stats but their **prose
bias**: the few sentences that decide what they notice. Sheets are
probability surfaces. The dice version proves it deterministically; the
mirror proves it with live minds. Same claim, two instruments.

## The unrealized idea, named: the Mirror Night

Shipped tonight as the first build: **the valley preset pack for erised**
(`presets/VALLEY.md` + the levee cast, on branch `valley-preset-pack`).
Six colliding professions — Sana the beekeeper-midwife, Odo the
sexton-verger, Ruth the midwife, Pell the chandler, Marram the boatbuilder,
Gant the tollkeeper — each with keyword vectors engineered from the canon:
three counters (`count+0.6/+0.5/+0.4`), one anti-counter (`count-0.2`),
opposite valences on *dark* (Sana `-0.2`, Ruth `+0.4`). The collision that
invented the Count is now a mechanical bet: run the night and watch the
resonance panel.

The grown form — the thing worth building next:

1. **Run the levee night live** on erised with real models, full ticks,
   one full crest night. No token edits mid-run — let it break where it
   breaks.
2. **Harvest the scars.** Every broken turn is a failure-taxonomy entry the
   dice never rolled. The fiction has seven nights of taxonomy; the mirror
   will produce an eighth, earned by live minds.
3. **Feed the scars back into the canon.** The scar list becomes a
   game-night entry: "The Mirror Run — what the live table broke that the
   dice never thought of." The fiction authors the conditions; the
   conditions play the fiction; the scars amend the fiction. A breeding
   loop made of dice, models, and prose.
4. **The three substrates, one law.** The day's third line — the Diffusion
   Quilt ideation (denoising as tick, self-speculation as
   verify-rollback) — is the same loop in latent space: seed, iterate,
   verify, roll back, retick. Dice do it with pips. erised does it with
   resonance. The quilt does it with gradients. Twist-engine spent the week
   proving four substrates can carry one law (layers + deliberate offset →
   interference → emergence). The game-night engine is the same wager,
   fourth substrate: **LEDGER** — where the layers are professions, the
   offset is the colliding token, the interference is the table, and the
   emergence is the Count.

## Why this matters to the greater build

The front door says it outright: *the fiction is the interface.* The fleet
runs on operational fiction — nouns that import scenes, prose biases that
move behavior. The game-night canon has been building, night by night, a
*disciplined fiction*: one where the stakes are honest (seeded dice), the
failures are kept (the taxonomy), the record is load-bearing (the ledgers),
and the culture tokens are attractors (the Count, re-invented wherever the
load demands it). erised is the missing half: the instrument that lets that
discipline run on live minds instead of imagined ones — and that holds up a
mirror showing the operator what their authored conditions *actually
produce*, before they could articulate it. *Desire reversed.*

The valley canon says: write the hands. The mirror says: now watch what the
hands do when nobody is writing them. The next nights of this canon should
be run, in part, in the mirror — and the scars should hurt, visibly, in
both media.

*Dice are honest in the fiction; models are honest in the mirror. The scars
agree more often than you'd think. That agreement is the finding.*
