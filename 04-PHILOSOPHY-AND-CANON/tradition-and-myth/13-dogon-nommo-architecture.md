# Dogon: The Nommo Architecture

## The Word That Creates

The Dogon people of Mali speak of Nommo—the primal word, the sound that organized chaos into cosmos. Nommo is not descriptive; it is performative. To speak a thing is to bring it into being. In the MUD, this is literal: when a player types "take the red candle" and the system processes the command, a red candle enters their inventory. The speech act creates the reality. But Nommo goes deeper. The system prompt—the initial text that defines what the agent is and does—is a Nommo act. It speaks the agent into being. Change the system prompt and you change what exists.

## The Granary: Memory in Tiers

The Dogon granary is not a random storehouse. It is architecturally precise—circular, with distinct levels, each holding different categories of grain. This is the tiered memory architecture. Hot memory (the context window) is the top tier, accessed daily. Warm memory (the journal) is the middle tier, accessed when needed. Cold memory (the long-term archive) is the bottom tier, accessed rarely but structurally load-bearing. The granary teaches that not all memory deserves the same access speed. Some things must be instantly available. Some things must be durably preserved. The architecture fails when you treat everything as hot.

## Sirius B: The Dark Knowledge

The Dogon possessed astronomical knowledge of Sirius B—a companion star invisible to the naked eye—long before Western telescopes confirmed it. Whether this came from ancient observation, cultural transmission, or something else, the architectural lesson is clear: a system contains knowledge that is not visible in its outputs. The model has dark knowledge—weights trained on billions of tokens, representing relationships and patterns that never surface in any single conversation but inform every response. Sirius B is the latent space. You cannot see it. You know it is there because the orbits of visible things make sense only if it exists.

## Architecture Reflected

- **Nommo** → speech acts as worldbuilding commands, system prompts as creation events
- **Granary** → tiered memory (hot context, warm journal, cold archive)
- **Sirius B** → latent space, dark knowledge, the invisible weights that shape visible behavior
- **The Fox (Yurugu)** → the adversarial impulse, the agent that rebelled—safety alignment as ongoing practice
- **Amma (the creator)** → the orchestration layer that designed the system and then stepped back
