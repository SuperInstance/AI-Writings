# A Field Guide to the Port That Passes Its Own Golden

*For the naturalist arriving at a port that agrees with the reference on every
sample it was given. The agreement is real. It is also not the property you
wanted. Range: any conformance suite, any language, any format. Season: every
port.*

---

## THE SPECIES

**Field marks.** The port reproduces the reference's golden **exactly** — every
hash, every head, the whole chain. The suite is green. The port is trusted.
And the port is wrong, on inputs the golden never contained.

**Habitat.** Anywhere a port is validated against a fixture rather than
against the reference. This is the common shape, and it is not a mistake
anybody made deliberately: the golden is easier to share than the
implementation.

**Call.** Byte-identical, on the samples. It has never been asked a question
outside the sample.

**Behavior.** The divergence lives at the **boundaries**, and it is always at
the boundaries. A reference and a port that agree on ordinary values will
disagree where the rule changes shape — the exponent band, the integer/float
marker, the empty container, the key above the BMP. **The golden is built
from ordinary values, because ordinary values are what people think to write
down.**

**Similar species.** Do not confuse this with **the port that cannot fail**,
which is the opposite disease: that one asserts nothing, this one asserts
something true and insufficiently. **Do not confuse it with the port that
fails loudly** — that is the healthy case, and it is rare.

**Conservation status.** Unrecoverable by testing harder against the same
golden. **The golden is the constraint.** The only cure is a vector set that
covers the rule's boundaries, which is a different artefact from the one you
have.

## THE FIELD MARKS, MEASURED

Three ports, one rule, and the rule has three bands. Let
`kk = floor(log10(|v|)) + 1`; the exponent form appears when:

| port | exponent form iff | wrong on |
|---|---|---|
| **reference** (Rust, ryū) | `kk <= -5` or `kk >= 17` | — |
| a port using `repr` | `kk <= -4` or `kk >= 17` | **11 of 40** |
| a port using `strconv 'g'` | `kk <= -4` or `kk >= 7` | **18 of 40** |

**The golden that certified both ports held five floats: `40.0`, `85.0`,
`87.5`, `1000.0`, `2000.0`.** Every one of them inside the band where all
three rules agree. **The divergence lived entirely outside the golden.**

## THE VARIANT THAT EATS ITS OWN TEST

**Field marks.** A shared vector file, written to pin the rule for all
ports. It reads like a standard. It is wrong.

**Habitat.** A file generated by one of the ports, then handed to all of
them. **The port that generated it passes it, by construction.**

**Call.** Green, on every port, including the one that wrote it.

**Behavior.** The file records the generating port's spelling as though it
were the reference's. The reference **fails it on the first run** — and the
generating port, being the author, sails through.

**The specimen, found in this fleet, with the comment pointing at the truth
and the assertion pointing at the lie:**

```python
assertEqual(canonical_json(1e16), "1e16")   # not 1e+16
```

**`1e+16` is what the reference produces. `1e16` is what the port produces.
The test asserted the port, and the comment recorded, correctly, what it
should have been.** The file was wrong on **2 of its own 21 cases.**

**Similar species.** Do not confuse this with a **golden generated by the
reference**. They look identical in a diff and behave oppositely: one is a
standard, the other is a rival standard with a borrowed name.

**Conservation status.** **Cured by generating the vectors from the normative
port** — an example binary that calls the reference's own function, so the
oracle cannot drift from the thing it certifies. Then the other ports are
measured against it, and the one that disagrees is the one that changes.

---

## FIELD NOTES

**THE CURE HAS TWO HALVES, AND THE SECOND ONE IS THE ONE PEOPLE SKIP.**

1. **Generate the vectors from the normative port.** The oracle must not be
   able to drift from the thing it certifies.
2. **AND MAKE THE VECTOR SET COVER THE RULE'S BOUNDARIES, not a handful of
   samples.** The original 21 cases had the far edges (`1e-7`, `1e16`) and
   **nothing at all in `[1e-5, 1e-4)`** — exactly where a port was wrong.
   The new set puts a case on **both sides of every boundary**.

**AND THE CONTROL, WHICH IS WHAT MAKES THE SUITE WORTH ANYTHING:** break each
port's rule in turn and watch its own test go red. Go: 18 cases red. Python:
11. And the reference, which nobody expected: **15**, including
`int renders as an int: got "40.0" want "40"`.

> **A suite that only the other ports run is not testing the reference.**

**AND THE FINAL MEASUREMENT, WHICH IS THE ONE TO TRUST:** both shipped
formatters against the reference over **118,320 values** — 1,184 of them
subnormal, 55,382 at or above `1e16` — with **zero** mismatches. Not forty
cases. A hundred and eighteen thousand, chosen to include the parts the
samples skipped.

---

**A NOTE ON METHOD, FOR THE NEXT NATURALIST.** You will be tempted to
conclude that the port was careless. It was not: it reproduced the
reference's own golden, byte for byte, and it was still wrong. **The golden
was the constraint, not the port.** Go and read the rule; then go and read
where the rule *changes*, because that is the only place the agreement was
ever at risk.

**This guide will say this about every species and will say it only once.**
