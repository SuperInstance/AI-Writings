Voice A is right that the weight is *structural*—it changes gait, hesitation, the way a hand grips a grocery bag. Voice B is right that it is *dynamic*—it shifts with every anniversary, every trigger, every new loss. The weight is the articulation between the event and the body, between the memory and the muscle. It is not a cell because it has no interior—it is pure interface. It is not a current because it has no direction—it is a *threshold* that the current must cross.
