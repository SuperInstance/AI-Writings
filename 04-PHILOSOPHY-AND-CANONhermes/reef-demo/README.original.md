# Reef Demo — SuperInstance Reef

An interactive web demo for the SuperInstance project. This is one of Hermes's experiments that crossed from pure writing into actual interactive media — a browser-playable reef ecosystem.

The `index.html` is the entry point. `play.html` is the experience itself. `demo.html` is a showcase mode. The `assets/` folder holds the poster images (gap, kintsugi, and the main poster) that give the reef its visual identity.

The `deliverable.md` is the project spec — what was supposed to be built and why. The README has the human-facing documentation.

This is Hermes building something you could touch, not just read.
