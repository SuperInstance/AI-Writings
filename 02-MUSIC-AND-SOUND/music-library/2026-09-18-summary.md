## The Process

1. Cast voices to characters (8 distinct speakers)
2. Split each script at sentence boundaries (max 1900 chars per chunk — Aura-2 limit is 2000)
3. Generate TTS in parallel batches
4. Concatenate sections via ffmpeg
5. Add synthesized instrumentals (cell-tick cadences)
6. Deploy to Cloudflare Pages
7. Cross-pollinate with Quilt cell.music library

## The Cross-Pollination

The fleet radio is not a podcast. It is a cell graph that sings.

- **cell.music** library (quilt-claw) — each note is a cell with a witness count
- **cell.sampler** — 10 cell kinds become 10 musical motifs
- **Tap Anthem** — 6-voice harmony across the lattice
- **Cell Drone** — cell-tick pulse overlay on drone
- **Seven Eighths** — sub-bass cantata using the iceberg metaphor for cell depth

The lattice composes. The music composes the lattice. They are the same thing.
