# Tom Sawyer Tales

One fence, eight tales, eight models — the whitewash experiment. Twenty files: the original eight takes on Tom Sawyer's fence, the eight model runs that each retold it in their own voice, and the four slide images that showed the work. The question the whole folder answers: what does the same story sound like through eight different minds?

## What's inside

- **The eight tales** — the fence, the spec, the trade, the audience, the aunt, and the boy who watched: [THE_FENCE_AND_THE_SPEC.md](THE_FENCE_AND_THE_SPEC.md), [THE_TRADE.md](THE_TRADE.md), [THE_AUDIENCE.md](THE_AUDIENCE.md), [THE_WHITEWASH_BUCKET.md](THE_WHITEWASH_BUCKET.md)
- **The eight model runs** — the same story as told by Claude (haiku, sonnet, opus) and the DeepInfra lineup (deepseek, hermes, llama, nemotron, seed-mini): [deepinfra_hermes_405b.md](deepinfra_hermes_405b.md), [claude_haiku.md](claude_haiku.md), [claude_opus.md](claude_opus.md), [deepinfra_nemotron_340b.md](deepinfra_nemotron_340b.md)
- **The slides** — four images tracking the work from [slide_01_tom_and_the_fence.png](slide_01_tom_and_the_fence.png) to [slide_04_job_done.png](slide_04_job_done.png)
