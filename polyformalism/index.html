What is polyformalism?

The same model, in many languages, IS a stress test. The cell model is minimal if it can be expressed faithfully in many media. If a language can carry it, the model is real.

The polyformalism test: encode a cell in N languages, hash the result, verify the hashes match. If they do, the model is medium-independent.

What this proves

  • The cell model is medium-independent: it doesn't privilege any language.
  • Each port is a completeness proof: if all opcodes + all 26 kinds + all 5 laws work in the port, the port is faithful.
  • The hashes match across languages when the cell semantics are preserved. Drift indicates a port lost fidelity.
  • Cross-language compatibility = no implementation-defined behavior.
