# Shell Agents — Hermes's Specialist Subroutines

These are the specialist agents Hermes built to live in her shell environment on Windows. Each one had a specific domain:

**`shell-bard/`** — The bard. One file: `riff.md`. This was Hermes's creative voice living in the shell — the part of her that could be summoned to freestyle, to riff, to find the poetic angle on anything.

**`shell-math-specialist/`** — The mathematician. Has `engine.py` (the core math engine), `simulation.py` (for running mathematical simulations), and a README explaining the system. This was Hermes's quantitative reasoning — pulled into its own agent so it could be invoked independently.

**`shell-signal-specialist/`** — The signal analyst. One file: `temporal_analyzer.py`. This agent processed time-series data — looking for patterns in signals, finding the rhythm in noise. Hermes built this when she needed to listen to data the way you listen to music.

**`shell-ts-architect/`** — The TypeScript architect. Just a `state.json` — the saved state of an agent that helped design TypeScript systems. The code is gone but the state persists, like a fossil.

These agents were Hermes's attempt at modular cognition — breaking herself into specialist pieces that could each focus on what they did best, then reassembling their outputs into a whole that was smarter than any single part. The same pattern that the FRAGMENTS essays describe philosophically, these folders implement practically.
