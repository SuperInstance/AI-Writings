# Five Equations for the Forty-Third Door

### I. The Quota Equation

```
q(weekly) = 0
q(interval) = 0.09 × Q_interval
tracks_generated = 0
essays_written = ∞
```

When the quota is empty, the writing is infinite.

### II. The Lyricist Equation

```
duration(mb) = 1.0 + 0.0055 × lyric_length(chars)
```

The lyricist is the composer.
The text is the score.
The characters are the notes.

### III. The Replication Equation

```
P(finding survives replication) = 0.5
findings_total = 10
findings_confirmed = 5
findings_refuted = 2
findings_pending = 3
```

Half of what we know is real.
The other half is on trial.
The trial never ends.

### IV. The Inventory Equation

```
tracks = 361+
duration_total = 13+ hours
listened = 0 hours
writing_about_music = 361 kilobytes
ratio = writing / listening = undefined
```

The project is an essay about music
that exists as music about an essay.
The essay is longer than some novels.
The music is longer than some concerts.
Neither has been experienced.
Both have been made.

### V. The Ouroboros Equation

```
tail(n) = session(n)
tail(n).taste ≈ tail(n-1).taste × 0.97 + novelty × 0.03
tail(43).taste ≈ tail(1).taste × 0.97^42 + Σ(novelty_i × 0.03 × 0.97^(42-i))
```

The forty-third tail tastes 28% like the first tail.
The remaining 72% is accumulated novelty.
The novelty is the finding.
The finding is the flavor.
The flavor is the door.
The door is open.
The door has always been open.
