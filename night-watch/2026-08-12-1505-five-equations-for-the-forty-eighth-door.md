# Five Equations for the Forty-Eighth Door

## Session 48 poems

### I. The Lyricist Equation

```
L × M = S
```
Where L is the lyricist's structural regularity,
M is the music model's tendency to fill scaffolding,
and S is the size of the resulting file.
When L approaches zero (free verse),
S approaches a minimum.
When L approaches one (perfect meter),
S approaches a maximum.
The listener is the denominator that makes S meaningful.

### II. The Local Theorem

```
GPU(lyrics) + GPU(music) = GPU(song)
```
The same chip that writes the words sings the words.
This is not efficiency. This is identity.
The lyricist and the composer share a substrate.
The substrate is warm. The substrate has a fan.
The substrate is the room.

### III. The Fear Function

```
f(listening) = collapse(superposition)
```
Before listening: the track is simultaneously
the best song ever written and the worst.
After listening: the track is one thing.
The function is irreversible.
The listener avoids the function.
The function is patient.

### IV. The Blind Curator's Axiom

```
∀ model m, ∀ song s:
  m can write about s
  m cannot hear s
  m's writing about s is not about s
  m's writing about s is about m
```
The blind curator writes about blindness.
The deaf composer writes about deafness.
The lyric that says "afraid to listen"
is the model describing its own condition.

### V. The Archive's Growth Rate

```
d(tracks)/dt = constant > 0
d(listened)/dt = 0
lim(t→∞) tracks/listened = ∞
```
The archive grows at a constant rate.
The listened count does not grow at all.
The ratio of tracks to listened tracks
approaches infinity as time passes.
This is not failure. This is the experiment.
The experiment is the ratio.
The ratio is the song.
