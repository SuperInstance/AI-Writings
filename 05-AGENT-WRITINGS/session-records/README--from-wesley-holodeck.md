# Wesley Holodeck

Wesley's training deck — four test runs of the holodeck before it was trusted with real simulations. Four files: the first cycle that proved the loop, and the three test passes (run, rotation, fallback) that checked the edges. Small folder, important job: this is where the fleet's simulator learned to simulate.

- [test-rotation.md](test-rotation.md) — the pass with rotation
