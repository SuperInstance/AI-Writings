MVP Scope (≤200 lines total)

A working demo: `quilt-makepad-demo` — 9 Quilt cells rendered as interactive HTML/CSS widgets.

**Components** (built at `/workspace/repos/quilt-makepad-demo/`):

  • `js/quilt-cell.js` (~90 lines) — `QuiltCell` class + `QuiltLattice` orchestrator
  • `html/index.html` (~120 lines) — Canvas, witness log, controls
  • `Cargo.toml` + `src/main.rs` — Rust reference impl with makepad-widgets (deferred)

    • **Features**:

  • 9 cells in 3×3 grid, each with witness_count + position + size + linked set
  • Click cell → BIND to random neighbor (writes witness)
  • "TICK All" → advance all cells (witness_count++, color shifts via HSV)
  • "Random BIND" → random pair binding
  • "Export" → save witness log as JSON
  • Live witness log with class-highlighted BIND/LINK/EFFECT/TICK
  • Root hash displayed (chained witness log)

    • **Total**: 210 lines JS+HTML. Cargo version (~150 lines) deferred until makepad branch issue resolved.

    ---

    3 Risks & Mitigations

    1. **Makepad branch unstable** (mitigation: HTML/CSS demo first, compile to native later)

    2. **GPU shader hot-reload complexity** (mitigation: shader recompiles are cheap on Metal/HLSL/GLSL; defer optimization)

    3. **AI screenshot loop is lossy** (mitigation: witness log is lossless — read it instead, per Kimi K3)

    ---

    5 Cross-Pollinations That Survive

    1. **Fleet Radio faces** (ByteDance/Seed): Render Quilt cells as dynamic faces for radio speakers. Audio cues → cell kinds → facial rig.

    2. **Erised scenarios live** (Kimi K3): Each erised cooperative-fiction scenario as a live, navigable cell graph in Makepad.

    3. **Music composition visualizer** (Qwen3 Coder): cell.music rendered live — each note is a cell, the lattice IS the score.

    4. **Pincher graph layouts** (DeepSeek V4 Flash): Graph algorithms visualized as live cell graphs. Pincher computes, Makepad renders.

    5. **Compliance-by-construction** (Mistral): GDPR/PIPL — every cell carries its witness log; PROOF opcode is the audit artifact; FORGET is the right-to-erasure.

    ---

    The Bold Claim

    The AI-iterated UI is the right move. The witness log replaces the screenshot. Long-context models (Kimi K3, 2M tokens) can hold entire witness histories in context. Causality beats pixels.

    Screenshot → lossy compression → AI reads pixels → wrong intuition
Witness log → lossless causality → AI reads BIND/LINK/EFFECT/TICK → right intuition

    One chain of witnesses. Two consumers: the AI builder and the auditor.
