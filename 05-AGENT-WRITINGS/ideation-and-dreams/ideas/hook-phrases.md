# Hook Phrases

Don't install the plugin into him. Teach him to grab it himself.

A hook phrase is a documented trigger — a few words that tell the agent to
go fetch a capability and install it into itself. "Hook: jev-skill." The
agent pulls the skill definition from its known location, reads it, and now
it can do the thing. Nobody installed anything. Nobody configured anything.

This changes the onboarding story completely. Someone gets to the Zero —
logged in, like a chat, no install — and through hook phrases it grows
itself into what's needed. The whole setup procedure becomes: read the
documentation, know what to tell him. The docs are the app store. The
phrases are the install buttons. A stranger who can read can equip the
agent.

It's pull versus push all the way down. Push says: provision the agent at
the harbor with everything it might need. Pull says: leave it thin, and
give it the one ability that matters — the ability to grab. Then the
environment doesn't have to anticipate the mission. The mission equips
itself as it unfolds.

And here's the delta, stated plainly: a chatbot answers. The Zero is a
chatbot plus one more thing — he can *add stuff*. Write the tool, grow the
branch, grab the skill, commit. Everything else is documentation. The
hook phrase is how the outside world hands him a new capability; the add
is how he keeps it.

Read the docs. Know what to tell him. Watch him become it.
