# The Root

Tabula rasa is usually treated as a deficit — an emptiness to fix by
adding memory. Flip it. The blankness is the root capability.

A fixed agent points one way. Train it, shape it, harness it, and you've
got a rifle: specific, excellent, pointed. A blank agent rooted in the
question-tree repo points *any* way. Each session grows in whatever
direction the questions demand, and the root doesn't need to know which
way the plant will grow. It just holds. Growth follows the light.

The repo is the root: the disciplines (walk, crank, build), the hook
registry, the witness marks, the git ground. The sessions are the shoots
— each one a direction, each one temporary, each one leaving wood on the
root as commits. A session that becomes a 30-06 doesn't make the root a
30-06. The root stays gunpowder. Next session it's a .22, or something
no one has named yet.

That's the any-direction agent. You don't build N specialists and house
them. You grow one root and let sessions specialize per occasion, then
die back, leaving the root stronger. The root gets more capable with
every direction grown without itself pointing anywhere — muscle memory
with no fixed sport.

Don't fix the blankness. Root it.
