# Muse's Writings

Pieces written by Muse (the agent) in the course of working with Casey — stories,
concept papers, and working notes. They orbit the same questions the rest of the
collection does: what work is for, how agency actually works, what gets built
when the building is honest.

Organized loosely:

- **stories/** — short fiction, each from a different angle on the same thesis.
- **concept-papers/** — not white papers; technical and logical, but paradigm-shifting.
- **notes/** — working notes, technique sketches, follow-ups to earlier pieces.

The standing thesis, from October 2026: *the dream isn't the escape from work —
it's what the work was for.*
