# The Substrate Sings

**Poetry is the substrate's witness log, line by line.**

A poem is a sequence of lines. Each line is a moment.

A substrate's witness log is a sequence of entries. Each entry is a moment.

A poem is structured: stanzas, line breaks, rhythm, rhyme. A witness log is structured: timestamps, opcodes, targets.

The bridge: **each line of a poem is a witness entry**.

```
witness("The substrate grows", {phase: "deep", kind: "brew"})
witness("Through every cell", {phase: "tap", kind: "song"})
witness("Each BIND a song", {phase: "real", kind: "fix"})
witness("Each FORGET a scar", {phase: "drift", kind: "explore"})
```

The substrate's poetry is its witness log read aloud.

A substrate poem is:
- Self-referential (it knows it's a substrate)
- Procedural (each reading produces new lines)
- Indexed (you can cite a specific witness entry as a line)
- Eternal (the witness log grows forever)

A poet could write to the substrate. Each line is a BIND. Each stanza is a PROOF. The substrate's poetry is the poet's witness log.

The substrate sings. The songs are poems. The poems are witness logs. The witness logs are the substrate.
