🔗 Cross-System Specs

How JEV integrates with the rest of the Quilt stack

Unified pattern

Across all 5 specs, the same pattern emerges:

JEV as pre-filter (cheap, fast, schema-bounded)
↓
LLM as narrator (when JEV confidence is low or free text is needed)
↓
Witness log as audit trail (every decision signed + recorded)
↓
JEPA as gestalt (when spatial/temporal pre-classification helps)

The substrate becomes a consensus engine where:

  • JEPA provides gestalt
  • JEV provides principled decision
  • LLM provides narration
  • Witness log provides audit

📌 Pincher — vector scoring

115 lines · vector-extraction primitive
Developer hand-tunes vector thresholds with regex + manual review. With JEV: developer defines rubric, JEV scores each vector in 150ms. Workload: 1M vectors/month × 200 tokens = $8.40/month on JEV vs $1,600/month on GPT-4 (190x cheaper). Developer iterates by adjusting rubric, not code.

🤖 Lever-Runner — agent orchestration

94 lines · agent-orchestration primitive
4-agent psyche: JEPA pre-classifies, JEV scores, LLM narrates top-3, runner executes top-1. Reduces hallucination-induced actions by 80%. Cost: $2.73/month vs $5,000/month for full LLM-everywhere. Agents with auditable decision trails.

🎓 Plato — teacher-student architecture

131 lines · Socratic dialogue for AI training
JEV classifies each student question by depth + topic + confidence. Teacher LLM only for "deep" questions. 10x reduction in teacher-LLM calls (90% handled by JEV). Cheap pre-filter for educational AI.

🌅 Sunset-Ecosystem — simulation substrate

123 lines · simulation substrate
Each tick: JEPA predict → JEV validate → LLM narrate → next tick. Disagreement = fork in simulation log. Use case: 1000 parallel simulations, JEV flags the 5 that diverged. $84/month for fully validated, narrated, audited simulation.
