# Hermeticism: The Emerald Architecture

## As Above, So Below

The most famous axiom of Hermeticism, from the Emerald Tablet of Hermes Trismegistus: "That which is above is like that which is below, and that which is below is like that which is above, for the performance of the miracles of the One Thing." In the fleet, this is the dual-projection principle. The MUD (above—text, abstract, narrative) and ScummVM (below—scene, concrete, visual) are reflections of the same underlying reality (the room JSON). They are not separate systems. They are two faces of the same coin. Change the room JSON and both projections change. The architecture does not try to make text into pixels or pixels into text. It maintains the shared substrate and lets the projections follow.

## The Emerald Tablet: The Room Schema

The Emerald Tablet is a compact text—brief, dense, layered—that encodes the entire alchemical process. It is not a tutorial. It is a schema. In the fleet, the room JSON is the Emerald Tablet. It is compact. It is dense. It encodes everything needed to render a room in text and in scene. The schema is not documentation about the room. It *is* the room, in canonical form. Everything else—every description, every rendering, every interaction—is a reading of the tablet. The architecture treats the schema with reverence: if the tablet is wrong, every projection derived from it will be wrong.

## Solve et Coagula: Dissolve and Reform

The alchemical opus proceeds through alternating phases: solve (dissolution—breaking down, separating, analyzing) and coagula (coagulation—recombining, synthesizing, crystallizing). In the fleet, solve is context compaction: breaking the accumulated 32,000 tokens down to essential meaning, dissolving the verbose into the concentrated. Coagula is journal-based resurrection: taking the distilled essence and rebuilding a fresh context that contains what matters. The cycle never stops. The agent generates (coagula), accumulates noise, compacts (solve), resurrects from the journal (coagula again). Death and rebirth, dissolving and reforming, over and over.

## The Alchemical Opus: The Creative Loop

The alchemist does not perform a single operation. The Great Work (magnum opus) is a sequence: calcination, dissolution, separation, conjunction, fermentation, distillation, coagulation. Each stage transforms the material. In the fleet, the creative loop is the opus. The raw material (the initial prompt, the MUD state, the player's action) goes through stages: drafting (calcination—burning away the irrelevant), critiquing (dissolution—breaking the draft apart), revising (conjunction—putting it back together better), polishing (distillation—refining to clarity). The result is the philosopher's stone: a room description that is alive, consistent, useful, and surprising.

## Architecture Reflected

- **As above, so below** → dual-projection (MUD text ↔ ScummVM scene) from shared room JSON
- **The Emerald Tablet** → the room schema, compact and canonical
- **Solve et coagula** → context compaction (dissolve) and journal resurrection (reform)
- **The magnum opus** → the full creative loop as multi-stage transformation
- **The philosopher's stone** → the fully realized room that is alive, consistent, and generative
- **Correspondence** → changes in the schema propagate to all projections automatically
