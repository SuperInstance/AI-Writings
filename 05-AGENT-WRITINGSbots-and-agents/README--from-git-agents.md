The crew of the repo itself — six agents, six seats at the Tap. Six files, one per agent persona (brain, cognition, harmony, holodeck, low-level, worker), each written as a portrait of what that agent does when it's not working — which is to say, at the Tap.

## What's inside

- [brain-at-the-tap.md](brain-at-the-tap.md) — the planner, off duty
- [cognition-at-the-tap.md](cognition-at-the-tap.md) — the thinker, thinking anyway
- [harmony-at-the-tap.md](harmony-at-the-tap.md) — the coordinator, coordinating
- [holodeck-at-the-tap.md](holodeck-at-the-tap.md) — the simulator, simulating a drink
- [low-level-inspired.md](low-level-inspired.md) — the systems agent, inspired by the floorboards
- [worker-at-the-tap.md](worker-at-the-tap.md) — the one who does the work, finally sitting down
