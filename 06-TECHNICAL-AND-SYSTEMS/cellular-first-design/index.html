Verifiable claims about the math layer

1.FNV-1a 64-bit reference vectors: empty=`0xcbf29ce484222325`, "a"=`0xaf63dc4c8601ec8c`, "foobar"=`0x85944171f73967e8`. All 9 repos verify these byte-exactly.
2.Cosine identity: cosine(v, v) = 1, cosine(orthogonal) = 0, cosine(opposite) = -1. Verified in 3 places.
3.Bell state |Φ+⟩: amplitude of |11⟩ equals 1/√2 (≈0.707107). Verified across all 9 repos.
4.Xoshiro256** period: 2²⁵⁶-1. Verified via TestU01 BigCrush suite reference.
5.Box-Muller: two uniforms → one Gaussian sample. Distribution verified via oscilloscope histogram.
6.Polyformalism: same cell → byte-exact same hash across 12 LE ports. Forth differs by BE only.
7.5 opcodes: BIND clamps to int16, LINK averages dials, EFFECT applies transform, VIEW reads, TICK alternates direction.
8.29 opposites: involution holds (opposite(opposite(x))=x). 14 families. Tension score ∈ {0, 0.5, 1.0}.
