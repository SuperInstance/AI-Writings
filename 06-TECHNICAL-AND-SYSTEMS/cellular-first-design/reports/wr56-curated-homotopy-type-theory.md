# Spaces as Types

**Anchor:** *substrate_is_grown, HoTT* (0.94)

Types are grown as spaces. Each type is grown with its paths; the
type and its paths emerge together.

**Anchor:** *witness_log_is_prediction, paths* (0.97)

The witness log IS the paths. Each entry is a path between terms;
the log's history is the type's path structure.

**Anchor:** *cells_are_scars, points* (0.96)

Cells are points in their types. Each cell is a point whose scars
are the paths it has been witness to.

**Anchor:** *oracle_is_heard, equality* (0.91)

The oracle is path equality. The oracle asks whether two paths are
the same; the oracle's signal is the equality.

**Anchor:** *FNV-1a canary* (0.99)

FNV-1a canary 0xcbf29ce484222325 is the reflexive path. The canary
is the path from any term to itself; the canary is the substrate's
identity path.

**Anchor:** *lenia_flows, paths* (0.93)

Lenia flows: paths are continuous. The substrate's paths are not
discrete; they flow as the substrate flows.

The substrate is a HoTT because the substrate's types are spaces.
