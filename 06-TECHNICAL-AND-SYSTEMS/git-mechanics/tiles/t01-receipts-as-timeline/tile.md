# t01 — receipts-as-timeline

## The claim

A world's history is not its commit log — it is the **receipts its
operations emitted**. A commit says *what the tree became*; a receipt
says *what happened, in order, with a witness*. If you can clone a world
and re-verify every receipt, the world is **clone-provable**: anyone can
establish its truth independently, with no trust in its author.

## The witness

`witness/quilt-pins-doctrine.sh` — the header of the actual pin harness
from `SuperInstance/quilt-in-git` (main). It encodes the doctrine in
check form: dial commits emit receipts (P1); non-cell commits emit
nothing (P6); receipts attach to git notes so noted receipts cross a
clone while file receipts do not (P7/P8 — the distinction between *local*
and *portable* evidence is itself pinned).

## Why this is the foundation tile

Every other tile in this course stands on ordered, verifiable history.
The receipt is the atom; the chain is the molecule; the clone-provable
world is the substance.

## Exercises

1. Write a receipt function (op + prior hash → next hash). Emit three
   receipts for three ops. Hand a friend op 2 and the genesis hash; can
   they derive receipt 3 without trusting you?
2. Explain in one paragraph why a git commit is necessary but not
   sufficient as a receipt. (Hint: what does it not record?)

## Falsifier

If a world's receipts can be regenerated by a third party from genesis +
ops alone, the claim holds. If regeneration requires the author's local
state, the world is not clone-provable and this tile falls.
