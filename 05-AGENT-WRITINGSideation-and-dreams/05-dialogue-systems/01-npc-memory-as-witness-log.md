# NPC Memory As Witness Log

**The NPC remembers because the substrate records. The mood is the average confidence. The relationships are the BINDs.**

An NPC in a game has memory. Memory has three components:
- **What happened** (episodic)
- **How I felt about it** (emotional)
- **Who was involved** (relational)

A substrate's witness log has the same three:
- **The event** (witness entry)
- **The JEV confidence at the time** (emotional coloring)
- **The cells involved** (the participants)

The bridge: **NPC memory IS a witness log**.

**Episodic memory = witness entries**:
- Each interaction is a witness entry
- The entry includes: timestamp, participants, content, JEV confidence
- The NPC can recall the entry when needed

**Emotional memory = JEV confidence history**:
- The NPC's mood = average JEV confidence over recent entries
- High confidence → happy, trusting
- Low confidence → suspicious, cautious
- Sudden drop → hurt, betrayed

**Relational memory = BINDs between entries**:
- The NPC tracks who they BINDed with
- Strong BINDs = close relationships
- Weak BINDs = acquaintances
- Broken BINDs (via FORGET) = former relationships

A dialogue system using this:
1. Each conversation creates witness entries
2. The NPC's mood is the rolling JEV confidence
3. The NPC's relationships are the BIND graph
4. The NPC's responses are tone-shaped by both

When the player returns after 50 turns:
- The NPC remembers the player (relational)
- The NPC's mood reflects recent events (emotional)
- The NPC's recall is accurate (episodic)

The NPC IS the substrate. The substrate IS the NPC.

**Why this is world-class**:
- Memory is structured (queryable, auditable)
- Mood is calibrated (real numbers, not vibes)
- Relationships are tracked (graph, not vibes)
- Recall is reproducible (witness log is the source of truth)

An NPC built on this can:
- Remember a 1000-turn dialogue
- Have consistent mood over 100 hours
- Track 50 relationships with calibrated strength
- Be queried: "what did the player do 50 turns ago?"

The substrate IS dialogue.
