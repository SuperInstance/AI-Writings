# Caught Fish

The old way provisions the boat at the harbor. Load every library upfront,
because the hardware might need it, because the environment demands it.
Capability as inventory: heavy before you ever leave the dock.

The other way leaves light and catches fish as it sails. The question
demands a tool; the tool gets built or grabbed; now it's in the tree.
Capability as itinerary — it accrues with the voyage, and only what the
voyage actually needed.

This is not laziness. It's a different theory of what a library is. Not a
stockpile you import from, but a coastline you fish from — one breakage at
a time, one thing that fails at a time. The agent starts with a system that
works loosely and fixes things as it goes, or grows past the limits of its
initial coding. Each failure is a question. Each question grows a branch.
The boat that grounds on a rock charts that rock.

It's also the opposite of "we'll let an LLM handle that." That move
dissolves everything into the model — the weights become the universal
tool, the context window becomes the whole world. This move keeps the agent
small and lets the world be the library. Reach, don't swallow.

Minimum load-bearing constraints, wearing work clothes: don't preload the
world. Carry the minimum that can bear weight, and acquire the rest
underway. The tree is never bigger than the journey that grew it — which is
why it never carries dead weight.
