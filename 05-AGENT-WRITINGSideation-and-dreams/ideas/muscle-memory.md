# Muscle Memory

Declarative memory is facts you recall. Procedural memory is moves your body
knows because it walked them a thousand times. You don't remember the
chart; your hands remember the harbor.

The question tree is the second kind. It doesn't recall answers — it knows
the paths. Ask, and it walks: matched question, witness marks checked, tool
run, crank turned. The motion gets smoother the more a branch is traveled,
which is precisely how muscle memory works. The bathymetric rule is a
training rule: the most-traveled passages get the most accurate charts, and
the most accurate charts get traveled most. A loop that tightens.

This is why it belongs as the Zero agent's prime equipment, not as a
database beside it. A database is something you consult. Muscle memory is
something you *are*. The agent doesn't look up how to act; the acting is
worn into the structure. New situations don't query the memory — they grow
it, the way a new route wears a new path, and the path is there next time
without thinking.

Facts rot. Moves persist. When the repo is the body and the questions are
the drills, the agent doesn't need to remember what it learned. It just
moves like something that did.
