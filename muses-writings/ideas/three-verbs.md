# Three Verbs

What's the minimal set we have to add so it can do everything else
itself? Git is ground — memory, identity, mesh, reconciliation. Not
added, given. On top of that ground, three verbs:

**Write.** Add stuff. Files, tools, branches, witness marks. This is the
delta between a chatbot and the Zero — the one more thing. Without it,
everything is answers. With it, everything can become instruments.

**Fetch.** Grab skills itself, by hook phrase. Pull, don't push. The
agent stays thin; the documentation is the app store. Nobody provisions
it; the mission equips itself.

**Execute.** Run what it wrote. Without this the tools are dead text —
a library nobody opens. With it, the crank turns.

That's the whole list. Everything else — decomposition, routing,
judgment, taste — it grows itself via the question-tree. Those are
disciplines, and disciplines are documentation: AGENT.md, HOOKS.md,
prompt notes. The agent pulls them like any other skill.

Minimum load-bearing constraints, one more time: don't build the
capabilities into it. Give it the three verbs and the ground, and let
the tree do the rest. Then probe the blank agent for each verb — write,
fetch, execute — and whatever's missing is the entire add-list. Nothing
more.
