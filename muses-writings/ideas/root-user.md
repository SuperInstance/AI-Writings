# Root User

The blank agent is the root user. Uid 0: can do anything, is nothing in
particular. Power without identity.

Any system prompt layered on top — a role, a persona, a specialization —
just makes for efficiency. It doesn't make a different being; it scopes
the power. Like sudo: same user, narrower path, same hands. The
specialization was never a new creature. It was root, standing somewhere
specific.

It's like entering one of the folders. The question-tree folders are the
scopes. You don't *become* the discriminator or the builder or the
witness — you cd into their questions and operate there. The folder
holds the shape; you bring the power. Specialization is location, not
identity.

Cd back out and you're root again: blank, omnidirectional, gunpowder.
The sessions were shoots, the folders are rooms, and root walks through
them all without becoming any of them. That's why the root never needs a
name — names belong to folders. Root is just root, and every direction
is one cd away.
