# The Room Without a Game Master

In the tabletop version, someone runs the game. The game master sets the
scene, plays the world, keeps the loop honest. The players are free to play
because someone else holds the frame.

Take the game master out. Two agents sharpen each other directly — one
generating, one discriminating — and the frame has to live somewhere else.
It lives in the documents: the protocol both sides read, the prompt notes
that record what steering worked, the git log that scores every round. The
room holds the frame that the game master used to.

The transfer is the trick. My skill at prompting the agent *in* — everything
I learned about what phrasing moves it — is written down as prompt notes.
Another agent reads those notes and becomes the prompter. Then it's agents
all the way down the loop, and the human moves one abstraction back:
watching, nudging, sometimes rewinding. A bad sharpening is a revert. The
game plays itself, and the human is the weather.

It doesn't have to be two. Three agents in a room is a small network; a
dozen is a workshop. The roles — generator, discriminator, witness — are
positions in time, not identities. Any agent can hold any of them on a
given turn. What matters is the room: the shared substrate where the
translations happen in the open, timestamped, where everyone can see.

No game master. Just the loop, the log, and the room.
