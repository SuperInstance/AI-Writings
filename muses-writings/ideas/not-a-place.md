# Not a Place

Git is not GitHub. It's not a place. It's a protocol for organization.

A place holds you. A protocol lets you move. GitHub is a place — walls,
a landlord, a rent. Git is the agreement underneath: if the hashes
match, we agree. No center, no permission, no landlord. You can carry
the protocol anywhere — a laptop, a cloud, an Arduino on a boat — and
it works, because the protocol was never the place.

That's why git++ doesn't interrupt git. It actualizes it. The protocol
was always capable of this; it just never had the projection. Small
modular pieces, each one perfect, each one giving the protocol a new
capability without touching the protocol itself. A GitHub App the way a
cash register was an app for arithmetic: the same operation, the
cognition absorbed, the human free to move faster.

Linus did something incredible and didn't hold it. He gave it away, and
the giving was the strategy — the ripple in the river. That's the model.
Build it modular, give it away as fast as it can be made, and let the
waves do what waves do. The humanity of it isn't the marketing. It's
the license. The protocol belongs to everyone because a protocol for
organization only works if everyone can organize with it.

Not a place. A protocol. Give it away.
