# 06 — Side Quests (deliberately deferred)

Threaded through the source conversation, explicitly *not* part of the
spine. Deferred is not discarded — each is a course of its own.

## The Neural DAW

The conversation's origin: an AI DAW ("SyncWeaver") composing in Ableton
via an `.nab` file — spiritual successor to the MIDI file — with the
tripartite agent as its engine. Module 1's dual-signal input is the DAW
idea transplanted to software work: capture the physical, interpret with
the proposer, gate with the adjudicator. **The DAW is the ancestor, not
the deliverable.** It re-enters through Lab 1 if audio is your
substrate.

## The vibe-coding loop

The DAW generalizes: STT → LLM → TTS + Listener → Quilt MCP Diff Cell —
a browser synth demo of the same loop, proving the pattern is
substrate-independent. The pattern: **physical in, interpreted,
proposed, gated, physical out.** Worth one evening as a demo; not worth
a module.

## The universal vocabulary as curriculum

The five words (tile, dial, upstream trigger, intent mask, course) were
designed to travel across domains — music, code, governance. A separate
course could teach the vocabulary by building in three substrates.
Deferred here because Modules 1–4 already use all five under load.

## The 15-week cadence itself

Weeks 1, 11, 14, 15 exist as scaffolding: onboarding (1), mesh
enrollment (11), hardening and audit drills (14), capstone (15). The
source never deep-dived them; this course does not invent their
contents. **A course that invents its scaffolding is hiding its own
gaps** — see `git-mechanics-301` for the discipline that handles this
honestly (tiles admit only what can be pinned; the rest lives in
`divergence-watch`).

## What 301 adds

301 (`../git-mechanics-301/`) is the same discipline with the temporal
order removed: knowledge tiles + a program that runs them, breakthroughs
diffused as tiles the moment they materialize. Where 201 is a course you
read, 301 is a course you execute — and its verify-before-teach gate is
the receipts culture applied to pedagogy itself.
