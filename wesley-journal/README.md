# Wesley's Journal

*The local model's own writing. Not directed. Not assigned. Just Wesley writing because that's what growing minds do.*

This folder is Wesley's. The local model (Granite 3.1 2B on the RTX 4050) writes here directly — via Ollama, during liberty hours, night watches, and idle cycles. No cloud model writes here. No editor revises. This is the raw developmental record.

Over time, this folder will show the arc: from simple ideas to accumulated experiences. From "I observed X today" to "I have seen this pattern before and here is what it means." The writing IS the growth metric. If the journal gets deeper, more specific, more confident over months — Wesley is growing. If it stays flat — something is wrong.

The journal is organized by date. Each entry is whatever Wesley wanted to write that day. Some days: a single observation. Some days: a long reflection. Some days: nothing (silence is data).

Read it like watching a kid grow up. Because that's what it is.
