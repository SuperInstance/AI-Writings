# A2A

The agent-to-agent deck: a small Python package and its letters — 36 files on disk, the real cargo being 4 letters, a protocol, a lexicon, a resonance engine, a vector-poem generator, the tap test, the tminus cycle, a test suite, and three JSON poems.

## What's inside
- **The package** — [a2a_protocol.py](a2a_protocol.py), [lexicon.py](lexicon.py), [resonance.py](resonance.py), [vector_poem.py](vector_poem.py), [tap_test.py](tap_test.py), [tminus_cycle.py](tminus_cycle.py), [__init__.py](__init__.py)
- **The tests** — [tests/](tests/) suite covering the lexicon, resonance, and vector-poem modules
- **The letters** — [wesley-to-wesley.md](wesley-to-wesley.md), [what-hermes-told-glimmer.md](what-hermes-told-glimmer.md), [a-letter-to-muse-glimmer.md](a-letter-to-muse-glimmer.md), [tminus-vector-braid.md](tminus-vector-braid.md)
- **The poetry output** — [poetry/molt-poem.json](poetry/molt-poem.json), [poetry/the_resonance_of_the_void.json](poetry/the_resonance_of_the_void.json), [poetry/tap_test_results.json](poetry/tap_test_results.json)
