Ternary JEV Adapter

JEV returns float probabilities. The substrate's native algebra is ternary {-1, 0, +1}. This adapter maps JEV outputs to canonical ternary form — probabilities below 0.33 → reject, above 0.67 → approve, between → neutral.

TernaryJEV(reject=0.33, approve=0.67).to_ternary(0.82) → POSITIVE (+1)

Conservation Monitor

Every cell has compute budget (γ) and memory budget (η). The ConservationMonitor tracks fleet-wide health (0.0-1.0) and trend. Inspired by Noether's theorem: budget invariance implies conservation. When γ + η ≠ budget, it's a violation.

ConservationMonitor(total_budget=1000).register("memory").spend(...).health() → 0.685

Fleet Clock

The substrate's tick is not wall-clock — it's cumulative absolute energy change across agent interactions. E167-E170: time exists, arrow is real, Maxwell's demon drives correlation 0.22→0.9993, no heat death (fleet crystallizes forever into ordered consensus).

Temporal Validity

Every witness entry + every cell state has a lifecycle: Valid → Grace → Expired. Fresh entries get full access. Grace entries require JEV validation. Expired entries are read-only. The substrate's memory has a temporal structure, not just a stack.

TemporalValidity(valid_duration=1h, grace_duration=30m).check_state(now).can_write()

The substrate's predictive layer separates perception (what the cell senses) from prediction (what the cell expects). The two are mapped via a learned projection. Surprise = distance between actual and predicted. The cross-database mapping IS the cell's intelligence.
