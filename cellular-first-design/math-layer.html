The math layer

Below the Quilt cell fabric sits a stack of substrate repos — pure math, no business logic, no cell semantics. Each repo is small enough to read in one sitting, documented enough to teach the math, tested enough to verify the byte-exact behavior, and shipped in TypeScript so it runs in browser, Node, and Deno without translation.

The substrate is byte-exact across 13 polyformalism ports: JavaScript, Python, C, Rust, Go, Haskell, J, Lua, Zig, Forth, SubLEQ, Verilog, VHDL. The same cell at the same dial vector produces the same FNV-1a 64-bit hash in every language.

substrate-vectors

1024-dimensional vector operations. The math underneath Quilt's semantic search, similarity, clustering, and JEV scoring.

Math

• cosine(a,b) = (a·b) / (‖a‖·‖b‖) — angle-based similarity, range [-1, 1]
• euclidean(a,b) = √(Σ(aᵢ-bᵢ)²) — distance, same units as space
• kMeans(points, k) — Lloyd's algorithm with k-means++ init (O(d·n·k·iter) competitive)
• silhouette = (b−a)/max(a,b) — cluster quality, range [-1, 1]
• productQuantizer(vs, m, k) — k-means per sub-vector, ~32× compression with ~5-10% recall loss
• geometricMedian — Weiszfeld iteration, cosine-friendly centroid

26/26 tests pass. Includes Vector.fromText deterministic FNV-1a-based embedder (zero deps) and Vector.normalize with epsilon-safe denominator.

substrate-rng

Seedable RNGs. Xoshiro256** is the default — passes TestU01's BigCrush suite, 256-bit state, period 2²⁵⁶-1.

Math

• Xoshiro256** — default, period 2²⁵⁶-1, byte-exact across platforms, state serialize/deserialize for replay
• PCG64 — period 2¹²⁸, alternative for cross-language parity (matches Haskell's PCG)
• SplitMix64 — fast seed derivation, used to bootstrap Xoshiro state
• stringToSeed — FNV-1a 64-bit of the seed string
• gaussian() — Box-Muller transform, two uniforms → one Gaussian sample
• poisson(λ) — Knuth's algorithm, λ events per unit time
• latinHypercube(n, k) — space-filling sampling for Monte Carlo

22/22 tests pass. Same seed → same sequence, byte-exact. Includes rng factory with default + custom state.

substrate-quantum

Classical state-vector simulation up to ~14 qubits. Bell states, GHZ, W, QFT, Grover, Deutsch-Jozsa — all verified.

Math

• |Φ+⟩ = (|00⟩+|11⟩)/√2 — Bell state, max entanglement (1 bit)
• |GHZₙ⟩ = (|0ⁿ⟩+|1ⁿ⟩)/√2 — n-qubit GHZ, verified for n=3,4
• QFT|1⟩ = |−⟩, QFT² = I — Quantum Fourier Transform verified
• Grover with optimal iteration count ⌊π/4·√N⌋ — verified finds marked item with >90% probability for n=4, n=6
• von Neumann entropy = -tr(ρ log ρ) — pure states have entropy 0, mixed states positive
• Entanglement entropy — bipartite cut, 1 bit for Bell, log(d) for maximally mixed

26/26 tests pass. Includes measure (Born rule, collapses), sampleHistogram (non-collapsing), and full controlled-gate support.

substrate-post-quantum

Quantum-safe crypto primitives. Merkle trees, WOTS one-time signatures, Ring-LWE, hash-chain PRNG. Toy implementations — use ML-KEM for production.

Math

• buildMerkleTree(leaves) + merkleProof + verifyMerkleProof — leaf-up proof with correct sibling order
• WOTS-OTS — pk[i] = sk hashed (max+i) times, sig[i] = sk hashed (max-count[i]) times. ONE-TIME — reuse leaks secret.
• Ring-LWE in ℤ_q[x]/(xⁿ+1) — polynomial add/sub/mul, Gaussian noise via Box-Muller, encrypt/decrypt roundtrip
• HashChainPRNG — HMAC-SHA-256 based, quantum-safe
• commit(x) + verifyCommitment(c, x) — SHA-256 commitments

19/19 tests pass. Includes full pqGenerate, pqSign, pqVerify combining WOTS + Merkle tree (XMSS-style).

substrate-embedding

Text → 1024-d vector embeddings. BGE-Large compatible dimension. Three embedders.

Math

• HashEmbedder — deterministic, no model. FNV-1a sub-seeds × LCG stream. Same input → same vector, always.
• MockSemanticEmbedder — tokenize → co-occurrence matrix → PMI → truncated SVD via power iteration + deflation. Demo quality, no model download.
• RemoteEmbedder — HTTP client for TEI, Infinity, FastEmbed, BGE servers. Production quality.
• tokenize, bagOfWords, cosine, topK — composable primitives.

15/15 tests pass. EMBEDDING_DIM = 1024 matches BGE-Large, so vectors are drop-in compatible.

substrate-opposites

Duality algebra. 29 canonical opposite pairs, 14 families, tension metric, dual-closure BFS.

Math

• opposite(x) = canonicalOpposite(x) — involution: opposite(opposite(x)) = x
• tension(a, b) ∈ {0, 0.5, 1.0} — 0 = unrelated, 0.5 = same family, 1.0 = exact opposite
• dualClosure(start, depth) — BFS through opposite graph, returns all dual pairs within depth
• vectorInverse(v), complement(s, U), juxtapose(a, b) — vector/set/string dualities

26/26 tests pass. 14 families: memory, truth, composition, time, connection, transformation, form, order, signal, wound, growth, agency, boundary, movement.

substrate-forge

The build pipeline. Cell compiler, fabric builder, polyformalism verifier, 5-opcode simulator.

Math

• compileCell(json) — validates 12 canonical cell kinds, fills 16-dial vector
• FabricBuilder — cells + LINK edges, state hash (FNV-1a 64-bit), connectivity check
• BIND — clamp dial to Q1.15 range. LINK — average dials. EFFECT — apply transform. VIEW — read. TICK — alternate dial direction.
• verifyCellForPort(cell, port) — 13 ports (JS/Python/C/Rust/Go/Haskell/J/Lua/Zig/Forth/SubLEQ/Verilog/VHDL), validates dial range + endianness
• crossPortHashConsistency(cell) — proves same cell produces same hash across LE ports

24/24 tests pass. Includes FNV-1a 64-bit with 3 reference test vectors (empty, "a", "foobar") that match the documented constants byte-exactly.

Polyformalism

The same cell in 13 languages produces the same hash. That's not just porting — that's verification.

PortDial rangeEndianness
js, python, j, lua[-1, 1]LE
c, rust, go, haskell, zig, subleq, verilog, vhdlint16 [-32768, 32767]LE
forthint16 [-32768, 32767]BE

The FNV-1a 64-bit hash for any cell is byte-exact across all 12 LE ports. Forth's hash differs only because of the endianness of the dial-vector serialization — the underlying FNV-1a algorithm is identical.
