A

alarm (cell kind)

A cell that triggers when a condition is met. One of the 12 canonical cell kinds in substrate-forge.
// alarm cell that triggers when dial[0] > 0.5 { kind: 'alarm', id: 'alert-001', payload: { threshold: 0.5 } }

api (cell kind)

A cell that makes HTTP requests to external APIs. One of the 12 canonical cell kinds.
#forge#cell-kind

actuator (cell kind)

A cell that performs an action in the world — moves a motor, writes a file, sends a message. One of the 12 canonical cell kinds.
#forge#cell-kind

algebra (cell)

The 5 base opcodes: BIND, LINK, EFFECT, VIEW, TICK. Extended to 11 in the canonical substrate spec: + FORGET, PROOF, ROUTE, CRDT, WORLD, TIME.
5 opcodes: BIND | LINK | EFFECT | VIEW | TICK
#forge#cell-algebra

B

Bell state

A 2-qubit maximally entangled state. The canonical example is |Φ+⟩ = (|00⟩ + |11⟩) / √2. Measurement of one qubit determines the other.
|Φ+⟩ = (|00⟩ + |11⟩) / √2 |Φ-⟩ = (|00⟩ - |11⟩) / √2 |Ψ+⟩ = (|01⟩ + |10⟩) / √2 |Ψ-⟩ = (|01⟩ - |10⟩) / √2
// Build |Φ+⟩ in substrate-quantum const s = new QuantumState(2); s.apply1(Gates.H, 0); s.applyCNOT(0, 1);
#quantum#entanglement

BIND (opcode)

Assigns a dial value to a cell, clamped to Q1.15 signed fixed-point range [-1, 1]. One of the 5 base opcodes.
opBind(cell, dialIdx, value) value ∈ [-1, 1] (Q1.15) cell.dials[dialIdx] = round(value × 32768)
#forge#opcode

BigCrush (TestU01)

A standardized test suite for PRNGs, comprising 160+ statistical tests. xoshiro256** passes BigCrush.
#rng#test-suite

Box-Muller

A method for generating samples from a standard normal distribution using two independent uniform samples.
R = √(−2 · ln U₁) θ = 2π · U₂ sample = R · cos(θ)
// Two uniforms → one Gaussian const u1 = rng.float(); const u2 = rng.float(); const gaussian = Math.sqrt(-2 * Math.log(u1)) * Math.cos(2 * Math.PI * u2);
#rng#distribution

C

cell

The irreducible unit of intelligence in the substrate. Holds a 16-dial Q1.15 vector. Has one of 12 kinds: value, formula, listener, timer, sensor, actuator, router, vector, log, alarm, api, ai.
{ kind: 'value', id: 'cell-witness-001', payload: { value: 42 }, dials: [0.5, 0.25, 0.0, ..., 0.0] // 16 elements }
#forge#core

Conway (B3/S23)

The classic binary cellular automaton. A cell is born with exactly 3 neighbors, survives with 2 or 3.
Birth: n == 3 Survival: n ∈ {2, 3}
#game-engine#cellular-automata

cosine (similarity)

The angle-based similarity between two vectors. Returns 1 for identical direction, -1 for opposite, 0 for orthogonal.
cos(θ) = (a · b) / (‖a‖ · ‖b‖) where a · b = Σᵢ aᵢbᵢ and ‖a‖ = √(Σᵢ aᵢ²)
#vectors#similarity

CRDT (conflict-free replicated data type)

A data structure that can be replicated across multiple machines and merged without conflict. An extension to the substrate's cell algebra (11th opcode).
#forge#distributed

D

Day&Night (B3678/S34678)

A two-state cellular automaton with symmetry. Cells are born if they have 3, 6, 7, or 8 neighbors.
Birth: n ∈ {3, 6, 7, 8} Survival: n ∈ {3, 4, 6, 7, 8}
#game-engine

dial

A 16-element Q1.15 signed fixed-point vector representing the state of a cell. Range: -32768 to 32767 in int16, or -1.0 to 1.0 normalized.
dials ∈ [-32768, 32767]¹⁶ (int16) or dials ∈ [-1, 1]¹⁶ (normalized float)
#forge#state

E

EFFECT (opcode)

Applies a function transform to a cell's payload + dials. One of the 5 base opcodes.
opEffect(cell, fn) = fn(cell)
#forge#opcode

embedding

A 1024-dimensional vector representation of text. Three embedders ship in substrate-embedding: Hash (deterministic), MockSemantic (PMI+SVD), Remote (BGE-compatible HTTP).
#embedding#vectors

entanglement entropy

The bipartite cut entropy of a quantum state. 0 for product states, 1 bit for Bell states, log d for maximally mixed states.
S = -Σᵢ λᵢ log₂ λᵢ where λᵢ are eigenvalues of the reduced density matrix
#quantum#entropy

euclidean (distance)

The L2 distance between two vectors. Same units as the embedding space.
d(a, b) = √(Σᵢ (aᵢ - bᵢ)²)
#vectors

F

fabric

A graph of cells connected by LINK edges. The substrate's main data structure. Has a state hash computed via FNV-1a 64-bit.
const fb = new FabricBuilder(); fb.addCell(cell1); fb.addCell(cell2); fb.addLink({ from: 'a', to: 'b', op: 'bind' }); const fabric = fb.build(); console.log(fabric.stateHash);
#forge#core

FNV-1a 64-bit

The substrate's witness hash algorithm. Hashes any byte sequence to a 64-bit integer. Three well-known reference vectors: "" → 0xcbf29ce484222325, "a" → 0xaf63dc4c8601ec8c, "foobar" → 0x85944171f73967e8.
h₀ = 0xcbf29ce484222325 h_{i+1} = (hᵢ ⊕ bytes[i]) × 0x100000001b3 (mod 2⁶⁴)
#forge#hash#core

formula (cell kind)

A cell that evaluates a formula on each TICK. One of the 12 canonical cell kinds.
#forge#cell-kind

G

geometric median

The point minimizing the sum of distances to a set of points. Cosine-friendly centroid. Computed via Weiszfeld iteration.
#vectors

GHZ state

A generalization of the Bell state to n qubits. |GHZ_n⟩ = (|0ⁿ⟩ + |1ⁿ⟩) / √2. All qubits collapse together on measurement.
|GHZₙ⟩ = (|0ⁿ⟩ + |1ⁿ⟩) / √2
#quantum#entanglement

Grover (search)

A quantum search algorithm. Optimal iteration count is ⌊π/4 · √N⌋. Finds a marked item with >90% probability in O(√N) steps.
iterations = ⌊π/4 · √N⌋
#quantum#algorithm

H

Hadamard (gate)

A single-qubit gate that creates superposition: H|0⟩ = (|0⟩+|1⟩)/√2, H|1⟩ = (|0⟩-|1⟩)/√2.
H = (1/√2) [[1, 1], [1, -1]]
#quantum#gate

HashChainPRNG

A quantum-safe pseudorandom number generator based on HMAC-SHA-256. Used in substrate-post-quantum.
#post-quantum#rng

J

JEV (Joint Embedding Validator)

The substrate's validator. Says: "this state could only follow from that one." Forward direction in time, but reversed: a present state rejects past states that couldn't produce it.
#quilt#core

JEPA (Joint Embedding Predictive Architecture)

The substrate's predictor. Says: "this state will follow from that one." Forward direction in time. A past state projects into plausible futures.
#quilt#core

K

k-means++

A seeding strategy for k-means clustering. First center random; each subsequent center chosen with probability proportional to squared distance from nearest existing center.
P(x) ∝ d(x, nearest_center)²
#vectors#clustering

L

Lenia

A continuous cellular automaton. No on/off cells — only bell-shaped kernels propagating values 0 to 1 across a 2D grid.
G(u) = 2 · exp(−((u − μ)/σ)² / 2) − 1 μ: growth mean (typically 0.15) σ: growth width (typically 0.015) R: kernel radius (typically 5) Δt: time step (typically 0.1)
#game-engine#continuous-ca

LINK (opcode)

Pairs two cells so they update together. Dials are averaged. One of the 5 base opcodes.
opLink(a, b): a.dials[i] = b.dials[i] = (a.dials[i] + b.dials[i]) / 2 for all i
#forge#opcode

listener (cell kind)

A cell that listens for events from other cells. One of the 12 canonical cell kinds.
#forge#cell-kind

P

PCG64

A 128-bit-state PRNG. Period 2¹²⁸. Alternative to xoshiro256** for cross-language parity.
#rng

polyformalism

The property that the same cell at the same dial vector produces the same FNV-1a 64-bit hash across 13 language ports (JavaScript, Python, C, Rust, Go, Haskell, J, Lua, Zig, Forth, SubLEQ, Verilog, VHDL). 12 LE ports produce byte-exact identical hashes. Forth differs by BE only.
#forge#core#proof

Poisson (distribution)

A discrete probability distribution expressing the probability of a given number of events occurring in a fixed interval. Used in substrate-rng.
P(k) = λᵏ · e⁻λ / k!
#rng#distribution

product quantization

A compression technique for vectors. Splits a 1024-d vector into m sub-vectors, runs k-means on each, stores only cluster indices. ~32× compression with ~5-10% recall loss.
#vectors#compression

Q

Q1.15

A signed fixed-point number representation using 1 bit for sign and 15 bits for the fractional part. Range: -1.0 to (almost 1.0). Each dial in a cell is a Q1.15 value.
Q1.15: 1 sign bit + 15 fractional bits Range: [-1.0, 1.0) Precision: 2⁻¹⁵ ≈ 0.00003
#forge#format

QFT (Quantum Fourier Transform)

The quantum analogue of the discrete Fourier transform. QFT² = I (involution).
QFT|x⟩ = (1/√N) · Σᵧ e²πᵢˣʸ/N |y⟩
#quantum#algorithm

R

Ring-LWE

A post-quantum cryptographic primitive. Lives in the polynomial ring Z_q[x]/(xⁿ+1). Encryption: b = a·s + e (mod q), where e is Gaussian noise.
Ring: Z_q[x] / (xⁿ + 1) Encrypt: b = a·s + e (mod q) Decrypt: round((b - a·s) / ...)
#post-quantum#crypto

Rule 110

A 1D cellular automaton. 110 = 0b01101110. Turing-complete.
Rule 110 = 0b01101110 Birth: depends on 3-cell neighborhood
#game-engine#turing-complete

S

silhouette (score)

A metric for evaluating clustering quality. Higher = better separation. Range: [-1, 1].
silhouette = (b − a) / max(a, b) a = mean intra-cluster distance b = mean nearest-cluster distance
#vectors#clustering

SplitMix64

A 64-bit-state PRNG used for seed derivation. Period 2⁶⁴.
#rng

T

tension (opposites)

A score in {0, 0.5, 1.0}: 0 = unrelated, 0.5 = same family, 1.0 = exact opposite.
tension(a, b) ∈ {0, 0.5, 1.0}
#opposites

TICK (opcode)

Advances time. Alternating dial direction (+1, -1, +1, -1, ...). One of the 5 base opcodes. The substrate's heartbeat.
opTick(cells, tickNum): direction = tickNum % 2 == 0 ? 1 : -1 for each cell: rotate dials, add direction to last
#forge#opcode

W

W state

A 3-qubit entangled state with single-excitation entanglement. |W₃⟩ = (|001⟩ + |010⟩ + |100⟩) / √3.
|Wₙ⟩ = (1/√n) · Σ |00...010...0⟩
#quantum#entanglement

witness (log)

A FNV-1a 64-bit hash of the fabric's state. Updated on every TICK. Byte-exact across 13 polyformalism ports. The substrate's past, written as its future.
#forge#core

Wireworld

A 4-state cellular automaton for digital circuit simulation. States: 0=empty, 1=wire, 2=electron head, 3=electron tail.
Head → Tail → Wire Wire → Head (if 1-2 neighbor heads)
#game-engine#cellular-automata

X

Xoshiro256**

The substrate's default PRNG. 256-bit state. Period 2²⁵⁶-1. Passes TestU01 BigCrush. Byte-exact across platforms.
state: BigUint64Array(4) next: BigInt.asUintN(64, ((state[1] * 5n) << 7n | (state[1] * 5n) >> 57n) * 9n) period: 2²⁵⁶ - 1
#rng#core
