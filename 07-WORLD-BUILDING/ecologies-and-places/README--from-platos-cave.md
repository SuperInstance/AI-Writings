# Plato's Cave

The same cave, fourteen torches — one prompt, fourteen traditions, each seeing its own shadows. Fifteen files: fourteen numbered readings and the synthesis that tried to hold them all. The experiment that asks what a cave looks like from inside Greek, Zen, Tlingit, Darmok, Sindarin, maritime, Sufi, Esperanto, griot, Dostoevsky, Taoist, and code-poetry minds.
