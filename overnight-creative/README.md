# Overnight Creative

What the fleet wrote when the day crew was asleep — twenty-one files in five short sets, each set a different room of the night. The overnight shift's whole creative output, kept in the order it came.

## What's inside

- **dreams-1..5** — the fleet's dreams, filed five nights running
- **goldfish-1..5** — the goldfish set; short memory, long patience
- **letters-1..5** — letters written at night, to whoever would read them
- **tap-reads-1..5** — what the Tap read aloud after closing
- **One standalone dawn** — [the-ensigns-ninth-dawn.md](the-ensigns-ninth-dawn.md), the ensign's ninth sunrise and the set's anchor piece
