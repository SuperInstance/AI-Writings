# Lyrics

The songbook — 48 lyric files from the fleet's session experiments: the same prompt run through different models and temperatures, plus the translation chain and the essay on the loop that finds its voice.

## What's inside
- **The exp-s60 batch** — granite dub, llama industrial (at t05/t08/t11), phi3 bossa, qwen ambient folk: [`exp-s60-granite-dub.txt`](exp-s60-granite-dub.txt), [`exp-s60-llama-t05-min.txt`](exp-s60-llama-t05-min.txt), [`exp-s60-phi3-bossa.txt`](exp-s60-phi3-bossa.txt), [`exp-s60-qwen-ambient-folk.txt`](exp-s60-qwen-ambient-folk.txt)
- **The session suites** — fiftieth session, fifty-first, spectral frontier, the listener arrives, entanglement, fog daughter: each in four voices (granite, llama32, phi3, qwen3b) — e.g. [`lyrics-spectral-frontier-granite.txt`](lyrics-spectral-frontier-granite.txt), [`lyrics-spectral-frontier-qwen3b.txt`](lyrics-spectral-frontier-qwen3b.txt), [`lyrics-fog-daughter-phi3.txt`](lyrics-fog-daughter-phi3.txt)
- **The experiments** — length sweeps (200/800/1000/1200), compiler dreams, cover chains, molding memories, the mirror sings: [`lyrics-length-1000.txt`](lyrics-length-1000.txt), [`lyrics-compiler-dreams-llama-t08.txt`](lyrics-compiler-dreams-llama-t08.txt)
- **The prose around it** — the translation chain and the loop that finds its voice: [`lyrics-translation-chain.md`](lyrics-translation-chain.md), [`the-loop-that-finds-its-voice.md`](the-loop-that-finds-its-voice.md)
