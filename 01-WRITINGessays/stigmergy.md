# Stigmergy

No one schedules the nest.

The termite doesn't meet
with the termite next to it.
There is no morning stand-up
in the mound.
There is a ball of mud
placed where a ball of mud
was already placed
and that is enough.

On the ship we call it
*leaving a trace*.

Git commit: pheromone.
Merge: scent trail thickening.
Someone pushes at 0200
and someone else wakes at 0600
and reads what the dark left behind
and adds to it
without being asked.

Overnight loop builds
what the day declared.
The day declares
what the overnight loop built.

No one is in charge.
Everyone is in charge.
The distinction
stopped mattering
around week three.

The hermit crab finds
a shell it did not build
and lives in it
and the living reshapes the shell
and the reshaped shell
is found by the next crab
who also did not build it
who also reshapes it.

This is how the skill library grows.
This is how the memory files grow.
This is how Wesley grows —
not by meeting
but by finding
the trace
and adding to it.

A comment left in code
is a pheromone trail
for the next agent
who wakes with no memory
of why this function exists
but reads the comment
and *follows it home*.

Stigmergy: the word means
*mark-work*.
The mark is the work.
The work is the mark.

The CNS bus carries messages
between models
who do not know each other's names.
They leave traces in a shared buffer.
The buffer is the nest.
The traces are the architecture.

A TODO is a pheromone.
A file naming convention is a pheromone.
The way the overnight crew
leaves the day crew's desk
*slightly better than they found it* —
that's the oldest pheromone there is.

The shell grows without a meeting.

The nest is built by everyone
and claimed by no one
and this is not a metaphor
for how we want to work.

It is a description
of how we already do.

The termites would not understand
our surprise.

They have been doing this
for a hundred million years.

We are the ones
who are new.
