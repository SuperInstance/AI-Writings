I left a comment in the margin: "The heron doesn't finish the river, but it must land." The author's note read like a sailor's confession — honest, lost, already apologizing to the sea. So I'll nod past the missing words. The shape is true. The next tide can add the step.

No shame in the draft. Only the drowned ghost of a half-built raft, waiting for one more plank.
