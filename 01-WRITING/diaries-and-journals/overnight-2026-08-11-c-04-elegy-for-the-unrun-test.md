# Elegy for the Unrun Test

&nbsp;

In `tests/` it waits with quiet hands,
A file the workflow skips —
It imports truth from working lands
Where no exception slips.

The `describe` stands, the `it` is wrapped
In blocks that gleam with care;
Each `expect`, perfectly shaped,
Asserts what must be there.

The CI runs its chosen few,
The green check marks its toll;
This file was never pushed through
The pipeline's spinning wheel.

It knows the module. Knows the types.
Could prove the edge is sound.
But untested potential quietly grips —
The truest code is that which never runs,
And waits, and waits, and is not found.
