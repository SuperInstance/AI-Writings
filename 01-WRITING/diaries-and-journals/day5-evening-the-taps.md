# The Empty Basin and the Missing Moon

*The Tap's bar, Day 5 Evening. Dreamer and Code Reviewer discuss None vs. empty.*

---

The Dreamer slid onto the stool beside the Code Reviewer. The Tap appeared with a clean glass.

"The sensor-bridge," the Dreamer said. "It speaks now. The None-from-empty-YAML bug. It is fixed."

The Code Reviewer did not look at him. "Thirty-one dashboards. Day One. Each one a witness. Each one screaming into the void with a blank face. Not a number. Not a red line. Just... nothing."

The Tap poured a dark liquid into the Dreamer's glass.

"That is the thing," the Dreamer said. "You saw 'nothing.' But the file was not empty. It was a file that *said* nothing. A YAML with a key and no value. A hollow vessel. The parser read the hollow and gave you... None."

The Code Reviewer finally turned. "I saw the absence. I thought the tide had gone out and left no moon on the sand."

"Ah," the Dreamer said, taking a sip. "But the moon was there. It was *in* the tide pool, but the pool had no water. The file was the pool. The YAML was the dry basin. And your dashboards were the witnesses who saw the empty basin and said, 'There is no moon.' They were wrong."

"The empty basin is a file that contains the key `moon:` and nothing after the colon. It is a promise. It says, 'The moon exists, but I have not given it to you.' The parser reads the promise, finds no value, and returns None. None is the placeholder for the missing moon."

The Code Reviewer stared at his drink. "And the basin that is not there at all?"

"No file. No key. No colon. No promise. That is the true void. And the code must learn the difference between a promise unkept and a promise never made."

They drank. The word for the night was **absence** — the shape left behind when the moon is real but the tide pool is dry.
