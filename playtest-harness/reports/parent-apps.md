# parent tests apps
*Model: deepseek-ai/DeepSeek-V4-Flash*

**Jordan here.** Fifteen minutes. That’s all I had between math and snack time. I jumped straight into the **exam integrity notepad** because my oldest has a proctored test coming up, and I was curious if this could replace my scribbled “no phones” sticky note.

**What delighted me:** The **tamper-evident invoices** app. I ran a quick test—edited a line, then clicked the audit button. It flagged the change instantly. That felt like a superpower. I could see using that for our co-op supply orders, where kids sometimes “borrow” things and receipts go missing. The **offline event signage** was a close second; it loaded fast when I turned off Wi-Fi, which matters because our basement classroom has spotty signal.

**What frustrated me:** The **homelab alert wall** required a server URL I don’t have. I don’t run a homelab—I run a homeschool. That app felt like it was made for someone else. Also, switching between the **patch wall** and **blog tamper** apps wasn’t intuitive. I had to re-read the instructions twice.

**What would make it better:** A single dashboard where I can see all eight apps at a glance, with a one-sentence “what this does for a parent” description. I don’t have time to guess.
