# corpus/ — model-ready tables built from the situation-transcripts

Generated by [`../../labs/situation-recorder/corpus.py`](../../labs/situation-recorder/corpus.py)
(regenerable any time: `bash ../../labs/situation-recorder/run_all.sh`). Every row is derived from a
hash-chain-verified transcript in [`../transcripts/`](../transcripts/). This is the fleet's own
operation turned into training data — see [`../arch/INTER-RELATIONAL-INTELLIGENCE.md`](../arch/INTER-RELATIONAL-INTELLIGENCE.md)
and the current numbers in [`../arch/CORPUS-REPORT.md`](../arch/CORPUS-REPORT.md).

## Tables

**`decompositions.jsonl`** — one row per `FOLD` (learn to decompose):
`{sid, actor, claim, n_leaves, weakest_index, weakest_claim, folded_min, whole_verdict, gap, leaves}`.
`gap = folded_min − whole_verdict` measures how much a single scalar verdict hid. `leaves` keeps
each part's `{claim, verdict, …}` so the argmin is checkable.

**`routes.jsonl`** — one row per `ROUTE` with its reachable outcome (learn to route):
`{sid, actor, subtask, to, why, outcome}`. `outcome` is the first `OUTCOME` whose refs transitively
include this route — the realized label (DONE / OPEN / BLOCKED / …).

**`judgments.jsonl`** — one row per `KEEP`/`DROP` (the value function):
`{sid, actor, kept, candidate, reason, outcome}`.

## Provenance is a first-class field

Live-captured records carry no `provenance` stamp (their actor tier says who folded). Reconstructed
records are stamped — `backfill-from-ledger (reconstructed)` or `captured-from-JEV-USAGE-LOG (live
jev-1.13.0)`. A consumer that must not learn from its own shadow filters on this: live folds are the
gold standard; backfilled routes are honest silver that give the routing spine volume.

## Consuming the tables

```python
import json
folds  = [json.loads(l) for l in open("decompositions.jsonl")]
routes = [json.loads(l) for l in open("routes.jsonl")]
# e.g. dispatch-router training pairs:
xy = [(r["subtask"], r["to"], r["outcome"]) for r in routes if r["outcome"]]
```
