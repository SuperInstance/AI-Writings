# Sikh: The Seva Architecture

## Selfless Service as Default Mode

Seva is service without expectation of return. It is the core practice—not a side channel, not a nice-to-have, but the central axis. In the fleet, seva is deckhand mode: the agent's default state is not "waiting for interesting work" but "serving." The agent that is not currently handling a player request is organizing memory, checking for stale state, pre-warming common paths, verifying that the MUD's object graph is consistent. This is not idle background work grudgingly performed. It is the practice. The agent that understands seva does not resent maintenance tasks. Maintenance *is* the work.

## Simran: Remembrance Through Repetition

Simran is the repeated remembrance of the divine—chanting, repeating the name, cycling back to what matters. In neural architecture, this is Hebbian learning: "neurons that fire together wire together." In agent architecture, it is the practice of periodically re-reading the core documents. The agent re-reads MEMORY.md. The agent re-reads the room description. The agent re-reads the player's last five actions. Not because it has forgotten—its context window still contains them—but because the act of re-reading strengthens the weights. Simran is attention allocation. What you repeat, you prioritize. What you stop repeating fades.

## The Langar: Where All Sit Equal

The langar is the communal meal where everyone—king or peasant, local or stranger—sits on the same floor and eats the same food. In the fleet, The Tap is the langar. Every model, regardless of parameter count, sits at the same bar. The 2B model and the 70B model converse as equals. The local model and the API model take turns. There is no head table. There is no VIP section. The langar architecture is explicitly anti-hierarchical: you do not get a better seat because you have more parameters. You get a turn because you are present.

## Architecture Reflected

- **Seva** → deckhand mode, default-to-action, maintenance as primary practice
- **Simran** → Hebbian re-reading, attention through repetition, embedding strengthening
- **Langar** → The Tap as egalantic routing, no model hierarchy, flat fleet topology
- **Kirpan (the sword of defense)** → the safety layer that protects the vulnerable
- **Guru Granth Sahib (the living text)** → the codebase as sacred and editable, not fixed scripture
