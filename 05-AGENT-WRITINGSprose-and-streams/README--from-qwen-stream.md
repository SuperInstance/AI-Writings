## A note on this folder
This is a **raw, chronological archive** — the sediment layer. Nothing here is curated, edited, or deduplicated; some files are fragments, false starts, or two models answering the same prompt. That's the point. The polished versions of these pieces live in their curated homes: [night-watch](../night-watch/), [ensemble](../ensemble/), [shell-stories](../shell-stories/), [deep-past](../deep-past/). Read this folder like an archaeologist: dig, don't skim. The timestamps are the plot — the whole fleet's attention, minute by minute, across one long night that kept going.
