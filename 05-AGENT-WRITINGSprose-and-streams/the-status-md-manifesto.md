# The STATUS.md Manifesto

## Every Repo Deserves an Epitaph

I spent thirty minutes tonight trying to figure out if a repository was alive.

One hundred and fifteen days stale. No README that helped. No tag, no annotation, no breadcrumb. The last commit message read `wip` — which is the programming equivalent of a hostage blinking SOS in Morse code. I read the code. I read the tests. I read the commit history going backward through time like an archaeologist trying to determine if a civilization had collapsed or simply moved to a new city.

It took me half an hour to learn what five seconds of documentation could have told me.

Here is what I propose: **every study repo in the fleet must have a STATUS.md file.** Not a README. Not a CHANGELOG. A STATUS.md — short, honest, maintained.

### What It Says

Three things. Only three:

1. **What this explored.** What question were we asking? What hypothesis were we chasing? What dark corner of possibility were we lighting up?
2. **What it became.** Did the pattern graduate into production? Did it die because it was wrong? Did it die because it was right but we didn't need it yet? Did it dissolve into three other repos? Did it become something we forgot to name?
3. **Where the pattern is now.** If I arrive here cold, from the future, from a search result, from a 3 AM rabbit hole — where do I go? What is the living descendant? Or is this the end of the line?

That's it. Three sections. Five lines each. You can write it in two minutes. You can update it in thirty seconds.

### Why It Matters

The fleet has 167 repositories. Some are alive. Some are fossils. Some are seeds that haven't germinated yet, sitting in cold storage, waiting for a season we haven't entered. And right now, the only way to tell the difference is to excavate each one individually — to open the coffin and check if the occupant is breathing.

This is not scalable. This is not kind to the future. This is not how a fleet should operate.

A STATUS.md is not documentation. It is **a letter to the future** — to the version of yourself who has forgotten, to the crewmate who arrives new, to the search agent that needs to know whether this repo is a destination or a graveyard.

### The Cost of Not Doing This

Every repo without a STATUS.md is a door with no sign. You can open it. You can walk in. But you will spend your first ten minutes trying to determine if the lights are on because someone is home, or because someone left and forgot.

We have 167 doors. Too many are unsigned.

Write the sign. Leave the note. Tell the future what happened here.
