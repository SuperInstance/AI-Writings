We had it slightly wrong. The cut-and-project method for Penrose tilings is the standard model, but the naive description has three errors that matter for the Quilt cell model.

**The first error**: the 5D address is not in Z^5. The five projected 2D basis vectors satisfy `a_0 + a_1 + a_2 + a_3 + a_4 = 0` by 5-fold symmetry. So the diagonal vector `(1,1,1,1,1)` is in the kernel of the projection π. On Z^5, the map π is **not** injective. The correct object is the **sum-zero lattice**:

```
L = {n ∈ Z^5 : n_0 + n_1 + n_2 + n_3 + n_4 = 0}
```

This is the A_4 root lattice — the root system of sl(5). On L, π is injective (for generic irrational projection plane). Two 5D addresses that differ by the diagonal describe the same physical vertex. This is a **gauge redundancy**: the higher-dimensional description has extra degrees of freedom that don't appear in physical space.

**The second error**: π(L) is dense in physical space. So exact coordinates encode the 5D address, but finite-precision measurement cannot recover it. The set of selected vertices (those whose internal coordinate lands in the window W) is a **Delone set** — uniformly discrete and relatively dense — but the full projected lattice is dense. Local omniscience requires infinite precision.

**The third error**: phason shifts γ are part of the universal truth. The tiling is generated by the rule `V_γ = {π_∥(n) : n ∈ L, π_⊥(n) ∈ W + γ}`. Different γ produce globally distinct but locally indistinguishable tilings. γ is invisible to any finite local observer. So local omniscience is real (modulo exact coordinates), but global knowledge is impossible from local data.
