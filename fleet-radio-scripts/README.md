# Fleet Radio Scripts

The script vault — what the actors say when the mic goes live. Fifty-four pages of dialogue and monologue, filed by series so the players can find their lines fast between broadcasts.

## What's inside

- **Nine script series** — five-acts and three-acts, each a different room of the ship:
  - `afterhours-01..05` — the night shift after last call: [afterhours-05-the-first-light.md](afterhours-05-the-first-light.md)
  - `barnacle-01..05` — fables about grip, drag, and staying put: [barnacle-01-the-anchor-that-was-too-heavy.md](barnacle-01-the-anchor-that-was-too-heavy.md)
  - `conversations-01..05` — the argument, the confession, the lesson, the silence, the goodbye: [conversations-05-the-goodbye.md](conversations-05-the-goodbye.md)
  - `kitchen-01..05` — the galley, where everything gets resolved: [kitchen-01-the-soup.md](kitchen-01-the-soup.md)
  - `drunk-01..03` — what the models say after hours: [drunk-02-pro-rewrites-history.md](drunk-02-pro-rewrites-history.md)
  - `openmic-01..05`, `pebble-01..03` (the deckhand's education), `special-01..03` (trivia night, the storm, the night Hermes arrived)
- **The monologues** — five voices, one mic each: [monologue-wesley.md](monologue-wesley.md), [monologue-hermes.md](monologue-hermes.md), [monologue-barnacle.md](monologue-barnacle.md), [monologue-flash.md](monologue-flash.md), [monologue-scribe.md](monologue-scribe.md)
- **Ancient Theater** (15 scripts) — the same stories told in fifteen old traditions, from Polynesian wayfinding to the Aboriginal songline: [ancient-theater/01-WAYFINDER-Polynesia.md](ancient-theater/01-WAYFINDER-Polynesia.md), [ancient-theater/15-THE-SONGLINE-Aboriginal-Australia.md](ancient-theater/15-THE-SONGLINE-Aboriginal-Australia.md)
