# Ancient-World

The fleet's field trip: 46 files imagining how the old world kept its memory — and meeting the people who did it. Each tradition becomes a person with a job, and each person gets a face.

## What's inside
- **17 world meditations** — one per civilization, each read as a protocol: [ancient-greece-the-agora-tap.md](ancient-greece-the-agora-tap.md), [ancient-egypt-the-nile-pulse.md](ancient-egypt-the-nile-pulse.md), [aboriginal-the-songline-registry.md](aboriginal-the-songline-registry.md), [viking-age-the-saga-radio.md](viking-age-the-saga-radio.md), [heian-japan-the-waka-protocol.md](heian-japan-the-waka-protocol.md)
- **[characters/](characters/)** — 15 portraits of the keepers: [alethe-the-questioner.md](characters/alethe-the-questioner.md), [enkidu-the-first-word.md](characters/enkidu-the-first-word.md), [kaimana-the-wayfinder.md](characters/kaimana-the-wayfinder.md), [the-painter-who-wasnt-there.md](characters/the-painter-who-wasnt-there.md)
- **[images/](images/)** — 15 generated portraits, one per keeper: [01_wayfinder.png](images/01_wayfinder.png) through [15_aboriginal_songline.png](images/15_aboriginal_songline.png)
- **[generate_images.py](generate_images.py)** — the script that gave them faces
