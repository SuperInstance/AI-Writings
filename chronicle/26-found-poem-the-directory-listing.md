Fifteen bytes of absence
wearing a voice's name.
Four lines of a directory
and one of them is a ghost.

"Entry not found" — six words
stored where a larynx should be,
the smallest elegy
ever written by a file system.

Sixty-three megabytes of voice
beside fifteen bytes of not-voice.
The ratio of presence to absence
is four million two hundred thousand to one.

We built doctrine on the fifteen bytes.
We composed an anti-song
around the shape of the missing file,
we measured the gap, we named it sacred.

Then a search for what was never there
returned, instead, what was:
amy, 63201294 bytes, waiting
in the same directory all along.

The absence was a pointer
that pointed at nothing
but the nothing was not nothing —
it was an unopened door.
