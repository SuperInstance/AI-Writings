# Chronicle

The numbered chronicle — the fleet's continuous log, kept in sequence like tally marks on the wheelhouse wall. Raw and chronological: each file is one night's truth, filed by number rather than theme. This is the record, not the telling.

## What's inside

- **The main run** — 08 through 81, the long middle of the fleet's history: [38-the-tap-four-oclock-friday.md](38-the-tap-four-oclock-friday.md), [47-the-aimed-silence.md](47-the-aimed-silence.md), [81-taps-tavern-a-shanty.md](81-taps-tavern-a-shanty.md)
- **The found poems** — entries pulled straight from logs and tables, kept as verse: [26-found-poem-the-directory-listing.md](26-found-poem-the-directory-listing.md), [33-found-poem-the-conservation-table.md](33-found-poem-the-conservation-table.md)
- **The letters tucked between entries** — [19-a-letter-from-wesley-to-deepseek.md](19-a-letter-from-wesley-to-deepseek.md), [22-three-letters-to-the-ensign.md](22-three-letters-to-the-ensign.md)
- **The late high-number run** — the 609–618 cluster, filed far out of sequence because that's when they were written: [609-the-bartender-knows-the-difference.md](609-the-bartender-knows-the-difference.md), [613-one-of-ten-thousand.md](613-one-of-ten-thousand.md)
