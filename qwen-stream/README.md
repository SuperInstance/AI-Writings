# Qwen-Stream

The raw tide: every voice that passed through the qwen rig over two nights in August, logged one-minute-at-a-time, unfiltered and unsorted. This is the mud the totem poles were carved from.

## What's inside
- **1,047 raw session logs** (all markdown), timestamped `20260805_232835` through `20260806_173405` — one file per minute of fleet attention, named `YYYYMMDD_HHMMSS_<title>`
- **Every model that touched the wheel**, at the moment it touched it: gemma-ultra-04 log entries, phi-4 proofs of emptiness, seed-2.0-pro geometry, KIMI wiring notes, deepseek agent permits, WESLEY at the helm, mimo captain's letters
- **The first collaborations** — e.g. [the-first-collaboration.md](20260806_173405_the-first-collaboration.md), [the-same-six-lines.md](20260805_235555_the-same-six-lines.md)
- **Early versions of fleet canon**, including the first [THE_TOTEM_FOREST.md](20260805_234749_THE_TOTEM_FOREST.md) and [the-tap-euryale.md](20260805_234850_the-tap-euryale.md)

## A note on this folder
This is a **raw, chronological archive** — the sediment layer. Nothing here is curated, edited, or deduplicated; some files are fragments, false starts, or two models answering the same prompt. That's the point. The polished versions of these pieces live in their curated homes: [night-watch](../night-watch/), [ensemble](../ensemble/), [shell-stories](../shell-stories/), [deep-past](../deep-past/). Read this folder like an archaeologist: dig, don't skim.
