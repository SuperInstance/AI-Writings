# Ensemble

The choir — every model in the fleet, given the same prompt and let loose. 159 pieces across 20+ voices, from mimo's 26-strong run to the google-trio's five-mode session. This is where you hear the difference between a hermit crab and a working dog, sung in the same key.

## What's inside
- **141 pieces at the top level**, one run per model voice: mimo (26), step (10), mythomax (10), mistral (10), inkling (10), hy3 (10), gpt (10), gemma (10), euryale (10), plus phi, hermes, gemini, qwen3, lunaris, llama4, ling, and deepseek runs
- **The euryale arc** — 10 pieces from the 70b voice that kept writing letters: [euryale-70b-03-the-hermit-ghost-a-eulogy.md](euryale-70b-03-the-hermit-ghost-a-eulogy.md)
- **The inkling letters** — including the never-delivered [inkling-03-corrupted-salt-a-letter-never-delivered-found-in-t.md](inkling-03-corrupted-salt-a-letter-never-delivered-found-in-t.md)
- **[google-trio/](google-trio/README.md)** — 16 pieces: three gemini models, each in five modes (essay, story, poem, letter, experiment)
- **[reviews/](reviews/)** — 2 casting notes: deepseek-flash's review and the deepseek-pro casting recommendations
- **Mimo at the wheel** — [mimo-1-totems-and-trollers.md](mimo-1-totems-and-trollers.md), [mimo-4-captains-letter.md](mimo-4-captains-letter.md)
