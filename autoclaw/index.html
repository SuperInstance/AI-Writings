🧠 autoclaw

A 24/7 crew of researchers, teachers, critics, and distillers — the active improver.

autoclaw is the substrate’s brain. Where brewery rounds are single LLM calls and eco-GAN is a single ML cycle, autoclaw is a persistent crew running continuously. It scans the canon. Notices gaps. Validates claims. Distills patterns. The web is the display. autoclaw is the engine.

👥 The crew — 4 roles, 4 substrate ops

RoleMaps toFunctionOutput
🔍 Researcher WITNESS Scans the canon. Notices gaps. Records events. new brew topics · gap reports · watch lists
📚 Teacher PROOF Generates Q&A about each substrate concept. Q&A pairs · 5 levels · learning paths
⚖️ Critic JEV Validates prose and code. Spots contradictions. confidence updates · contradiction reports · citations
🧠 Distiller BIND Batches entries into knowledge summaries. JSONL exports · pattern detection · canon pieces

🌊 Active improvement flow

[researcher] scans ai-writings canon (4841+ commits, 100+ brews) ↓ notices gap ↓ writes witness entry [teacher] generates Q&A pairs for the gap ↓ produces 5 proofs (claim + evidence + counter) [critic] validates each proof via JEV ↓ adjusts confidence scores ↓ flag contradictions to substrate [distiller] batches into a canon piece ↓ publishes to live-canon ↓ the webpage improves itself

🔗 Integration with other systems

vs. Brewery rounds

Brewery = single LLM call per brew (100+ brews so far). autoclaw = persistent crew that improves the brewery. The crew watches what brews succeed, what gaps remain, what new topics emerge.

vs. Eco-GAN

Eco-GAN = single ML cycle: generator → judge → training data growth. autoclaw = persistent engine running many cycles. The crew IS the cycle’s memory.

vs. Crab-Traps

Crab-Traps = rooms with entrance/exit states. autoclaw = the crew that learns which rooms work best. Every visitor’s exit state feeds the critic’s confidence.

vs. Twist-Engine

Twist-Engine = 5 physics demos (TWIST/FLOCK/CHIRP/QUILT/PERM). autoclaw = the crew that discovers new substrates. The twist-engine is the lab; autoclaw is the researcher.

vs. Substrate-Forge

Substrate-Forge = 13 lower-level repos (rng, vectors, gan, game-engine, etc.). autoclaw = the crew that validates + tests each forge repo. Every forge repo gets a teacher’s Q&A and a critic’s review.

vs. Erised

Erised = cooperative fiction engine. autoclaw = the crew that reads + critiques the cast sheets. The crew’s scar count mirrors the fiction’s resonance shifts.
