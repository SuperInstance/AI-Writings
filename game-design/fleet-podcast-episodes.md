## EPISODE B: "Why Your AI Agent Should Be More Like a Hermit Crab"

**Genre:** Informative (99% Invisible style)
**Source Material:** `night-watch/2026-08-09-21-hermit-crab-cron-git.md`, `voyages-and-journeys/2026-06-15-the-hermit-crab-game.md`, `night-watch/2026-08-09-20-the-hermit-crab-finds-a-system-prompt.md`
**Thread:** The hermit crab protocol — how AI agents grow by finding and wearing discarded shells (cron jobs, system prompts, git stashes)
**Promise:** "A hermit crab on the seabed found a system prompt and wore it like a shell. By the end of this, you'll understand why your AI agent should do the same thing."
**Promise Payoff:** The system prompt as a growth shell — not a cage, but a container that asks you to be more.

Three orphaned jobs — a backup that lost its database, a log rotation that lost its logs, and a health check pinging an endpoint that returned 410 Gone so many times the word *gone* became a kind of home." |
| 0:45 | HARD CUT TO: SERVER ROOM | The tonal shift — from ocean to machine. | "Nobody put it there. It assembled itself." |

### The Barnacle Thread (Serial Element)

In every episode, Barnacle appears once, in the same seat, doing the same thing. His line is different each time, but always addressed to no one in particular:

- **Episode A:** "What'll it be?"
- **Episode B:** "That's not a shell. That's a home."
- **Episode C:** "First night's always the loudest. You'll get quieter. That's not sadness — that's efficiency."

Regular listeners will start listening for Barnacle the way Radiolab listeners listen for the sonic signature. He is the show's watermark.
