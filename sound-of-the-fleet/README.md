# Sound of the Fleet

The acoustics lab — 6 files where the fleet makes itself audible: a manifest, a soundscape (wav), the generator, and three essays on what the fleet sounds like. The fleet breathes in C major.

## What's inside
- **The sound itself** — the soundscape wav and the python that made it: [`fleet-soundscape.wav`](fleet-soundscape.wav), [`fleet_soundscape.py`](fleet_soundscape.py), plus the manifest: [`fleet-manifest.json`](fleet-manifest.json)
- **The listening essays** — the fleet breathes in C major, the sound signal at first light, what the organ hears: [`the-fleet-breathes-in-c-major.md`](the-fleet-breathes-in-c-major.md), [`the-sound-signal-at-first-light.md`](the-sound-signal-at-first-light.md), [`what-the-organ-hears.md`](what-the-organ-hears.md)
