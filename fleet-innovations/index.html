PRIMITIVE 1

🔺 Ternary Values

JEV float → substrate {-1, 0, +1}

Every JEV decision has a canonical ternary form. Probabilities below 0.33 → reject, above 0.67 → approve, between → neutral. The substrate's natural algebra is ternary — decisions are approve/neutral/reject, not floats.

TernaryJEV(reject=0.33, approve=0.67) .to_ternary(0.82) → POSITIVE (+1) .to_ternary(0.50) → NEUTRAL (0) .to_ternary(0.15) → NEGATIVE (-1)

PRIMITIVE 2

⚖️ Conservation Monitor

γ + η = budget, Noether-style

Every cell has compute budget (γ) and memory budget (η). The ConservationMonitor tracks fleet-wide health (0.0-1.0) and trend (improving/degrading/stable). When γ + η ≠ budget, it's not just a bug — it's a conservation violation. Inspired by Noether's theorem: budget invariance implies conservation.

ConservationMonitor(total_budget=1000) .register("memory", budget=200, γ=50, η=30) .spend("memory", compute=80, memory=40) .health() → 0.685 .violations() → ['mood', 'personality', ...]

Source: spreadsheet-engine

PRIMITIVE 4

⏳ Temporal Validity

Valid → Grace → Expired lifecycle

Every witness entry + every cell state has a temporal lifecycle. Fresh entries get full access. Grace entries require JEV validation. Expired entries are read-only but the witness log stays queryable. The substrate's memory has a temporal structure.

TemporalValidity( valid_duration=1h, grace_duration=30m ) .check_state(now) .can_write() → True/False .requires_jev_validation() → True/False

Source: plato-temporal-validity

PRIMITIVE 5

🧠 JEPA Dual-Database

Perception + prediction, separate spaces

The substrate's predictive layer separates perception (what the cell senses) from prediction (what the cell expects). The two are mapped via a learned projection. Surprise = distance between actual and predicted. The cross-database mapping IS the cell's intelligence.

DualJEPADatabase(dim=8) .add_perception("t0", [1.0, 0.5, 0.2, 0.1]) .predict("t0") → Vector .surprise("t0") → 0.105 .update("t0") → reduces surprise

Source: plato-jepa-dual
