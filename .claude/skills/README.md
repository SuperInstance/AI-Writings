### A note on depositing work here

This is a machinery folder, not a shelf for writing. New writing belongs in the
sections of the library - see [`00-START-HERE/HOW-TO-FIND-A-WRITING.md`](../00-START-HERE/HOW-TO-FIND-A-WRITING.md)
for the map and [`00-START-HERE/HOW-TO-ADD-A-WRITING.md`](../00-START-HERE/HOW-TO-ADD-A-WRITING.md)
for how to add a piece. If you are changing code here, open a pull request that
names one approving reader, and say what broke if the change does not land.

Every distinct work in the repository is also filed inside the library sections;
this copy is the one the machinery actually runs.
