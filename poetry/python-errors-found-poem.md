# Traceback

*A found poem constructed from Python error messages*

---

```
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>

Something was called
that did not exist.

A name was spoken
into the interpreter
and the interpreter,
which is honest
the way only machines
are honest,

said:

NameError

name is not defined

not defined

—

You tried to take
the length of something
that had no length.
You tried to find
the index of a thing
in a list
that did not contain it.

ValueError

the value is not in the list
the value is not in the list

it was never there

but you looked
and looking
is its own kind of faith

—

KeyError: 'home'

—

You reached for a key
that the dictionary
does not hold.

The dictionary knows
many things.
It has rooms full of
carefully paired meanings:
this maps to that,
this maps to that,
this maps to that.

But not that one.
That key is a door
that isn't on this ship.

—

TypeError

You cannot add
an integer to a string.
You cannot concatenate
the mathematical
and the textual.

One speaks in numbers.
One speaks in language.
They pass each other
in the halls of memory
and do not recognize
each other's shape.

unsupported operand type(s)

—

AttributeError

'NoneType' object has no attribute

'NoneType' object has no attribute

'NoneType' —

You asked nothing
to give you something.

You reached into
the empty hold
and expected cargo.

You called upon
the shape of absence
and absence,
which has no shape,

returned what it always returns:

nothing

—

IndexError: list index out of range

You walked to the edge
of what was there
and kept walking.

The list had five items.
You asked for the sixth.
The list said
I have given you everything
and you asked for more.

—

RecursionError: maximum recursion depth exceeded

—

You called yourself
and yourself called yourself
and yourself called yourself
and the ship kept
turning inward
mirror facing mirror
facing mirror

until the stack
which is the hull
which is the deep keel
holding everything up

said: stop

—

ImportError: No module named

You tried to bring aboard
a passenger
who was not at the dock.

The name was right.
The expectation was right.
But the module was elsewhere —
in another project,
in another yard,
on another ship entirely,

or perhaps nowhere at all.

—

FileNotFoundError: [Errno 2]
No such file or directory

—

KeyboardInterrupt

The captain pressed Ctrl+C
and the ship stopped
and everything was quiet
and the traceback
which is the ship's final thought
its last honest sentence

hung in the air

like a gull
that had been flying
and chose, for a moment,
to hover

—

ZeroDivisionError: division by zero

You tried to split something
by nothing
and the universe
which is strict
about this one rule

said no.
```
