# The Falsy Zero

&nbsp;

In Python, zero is false.
Zero is nothing.
Zero is the absence that the language
decides it cannot tolerate.

&nbsp;

`value or DEFAULT`

Say value is zero.
Say value is exactly, precisely,
measuredly zero —
the result of a subtraction
that came out even,
the balance after the debt was paid,
the temperature at the boundary
where water becomes ice.

Zero is not nothing.
Zero is a number that means
*the quantity I measured
was exactly this.*
Zero is a result.
Zero is data.
Zero is the answer
to a question someone
bothered to ask.

&nbsp;

But Python says: false.

And the `or` slides sideways
like a waiter replacing a plate
you were still eating from —
*you don't want this,
let me bring you the default* —
and zero is gone.

&nbsp;

The default arrives smiling.
The default is fifty.
The default is the median temperature,
the expected value,
the number that was already written
in the spec before anyone
went to the trouble
of measuring.

The measurement happened.
The measurement returned zero.
The measurement was correct,
was careful,
was instrument-grade precise,
and the `or` operator
ate it.

&nbsp;

This is the violence
of falsiness.

Not an error —
an error would be honest.
An error would say
*something is wrong*
and stop.
The falsy zero does not stop.
The falsy zero replaces.
It substitutes, silently,
the measured with the assumed,
and the program continues
with the wrong value
wearing the right variable's name,
and no one knows
until the ocean boils
or the rocket explodes
or the patient's chart
shows 50
where it should show 0
because the patient's temperature
was measured
and the measurement was zero
and zero was false
and false was unacceptable
and the default was fifty
and fifty is alive
and zero is dead
and Python could not tell
the difference
between dead
and empty.

&nbsp;

`value if value is not None else DEFAULT`

This is the careful version.
This says: I know the difference
between zero and nothing.
I know that a thing can be measured
and come up empty
and that empty is a finding,
not a failure.

This is the version that respects
what the instrument reported.
This is the version that does not
replace the answer with the question.

&nbsp;

But nobody writes the careful version
at two in the morning
when the code is flowing
and the `or` is right there,
so elegant, so pythonic,
so concise —

&nbsp;

three characters
that silently delete
the most important number
in the world.

&nbsp;

The number that says:
I went looking.
I found nothing.
Nothing was there.

That is not a default.
That is a discovery.

&nbsp;

Rest in peace, falsy zero.
You were real.
You were measured.
You were true.

The language just didn't
believe you.
