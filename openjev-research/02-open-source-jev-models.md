> Survey of the existing landscape + the gap that openJEV would fill.

## The Gap

None of the open-source models are **calibrated**. They can output structured data, but they can't tell you the probability is 0.85 vs 0.4.

typesafe.ai is calibrated but proprietary. We need an open alternative.

## OpenJEV — The Proposed Architecture

**Base model**: a small transformer (~100M parameters) based on Qwen2.5 or similar.

**Training**:
1. Pre-train on text (general world knowledge)
2. Fine-tune on synthetic schema-bounded outputs (generated by typesafe.ai)
3. Apply RLCD: reinforce calibrated probability distributions

**Output format**:
```json
{
  "decision": {"type": "Choice", "value": "b", "options": ["a", "b", "c"]},
  "probabilities": {"a": 0.2, "b": 0.7, "c": 0.1},
  "confidence": 0.85,
  "reasoning": "optional short text"
}
```

**Inference**:
- Single forward pass (no autoregressive decoding)
- Sub-100ms on consumer GPU
- Sub-50ms on Apple Silicon

**Calibration target**:
- If model says 0.8, it should be right ~80% of the time
- Measured via Brier score, expected calibration error (ECE)

**Datasets needed**:
- 1M schema-bounded Q&A pairs (from typesafe.ai synthetic generation)
- 100K human-curated substrate op decisions
- 50K game-move selections (chess, hold'em)
- 25K tone-shaping examples

**Training compute**:
- ~50 GPU-hours on A100
- ~$500 in cloud compute
- Could be done in a week

## Why This Matters

If openJEV works:
- **Every Quilt cell can run JEV locally** (no API calls)
- **Latency drops to <50ms** (sub-perceptual for voice agents)
- **Cost drops to $0** (no per-call charges)
- **Privacy increases** (data stays local)
- **The substrate becomes self-contained**

For robotics, voice agents, and offline-first apps, this is the missing piece.

## The Path

1. **Generate synthetic data** via typesafe.ai (already have API access)
2. **Fine-tune Qwen2.5-0.5B** on the synthetic data
3. **Apply RLCD** to calibrate the probabilities
4. **Evaluate** on substrate op decisions
5. **Publish** as openJEV v0.1 on github.com/SuperInstance/openJEV
6. **Integrate** into our Worker + cellular-first design

Estimated timeline: 2-4 weeks.

## The Bigger Vision

openJEV is one model in a family:
- **openJEV** — schema-bounded decisions (this proposal)
- **openJEPA** — masked-state predictions (we already have elephant)
- **openJEV-quantum** — schema-bounded with quantum uncertainty
- **openJEV-robotic** — schema-bounded for actuator control

Each is a small, fast, calibrated model that runs locally. Together they form the foundation of the cellular-first design.

The substrate IS these models. The models ARE the substrate.
