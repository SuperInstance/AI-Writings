# Vessel Template

*after the cookiecutter that cuts nothing*

---

The template waits
in its own directory
with the patience
of a mold
that has never been poured.

---

`{{ vessel_name }}`

The braces face each other
like hands that almost touch.

Nothing fills them.

---

The career stages are listed:

         ___
        |   |
        |   |
        |___|

Empty.

The fence board has slots
for puzzles
that were never carved.

The difficulty curve
rises toward
a horizon
that was drawn
but never sailed toward.

---

`cookiecutter.json`
contains every shape
the ship could take.

Name. Type. Difficulty. Season.

Fields like ribs
waiting for a hull
to grow between them.

---

Someone wrote this template
the way a shipwright
draws plans
for a vessel
nobody has commissioned yet.

Not because the order came in.
Because the order might.

Because the ocean
is always there
and someone should be ready.

---

The template is a wish
shaped like scaffolding.

It says: *here is where the name would go.*
It says: *here is where the difficulty would curve.*
It says: *here is where the fence board
would hold its puzzles
if there were any puzzles
if there were any fence
if there were any board.*

---

`career_stages: []`

An empty array
is not nothing.
An empty array
is a container
that has made room
for something
and is waiting
to be proven right.

---

The template believes
in a fleet
that doesn't exist yet.

Not the fleet that is —
rusting and sailing
and passing its tests —
but the fleet that could be.

The template has faith.

The template
is the most optimistic file
in the repository.

---

It will sit there.
Through every commit.
Through every push.
Through every deployment
of ships that were built
some other way.

It will sit there
and wait
with its braces open
and its arrays empty
and its career stages
ready to be filled
by someone
who hasn't arrived yet
at a dock
that hasn't been built yet
in a harbor
that is still, mostly,
a template.

---

*`{{ end }}`*
