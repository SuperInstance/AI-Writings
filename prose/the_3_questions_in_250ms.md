# The 3 Questions In 250Ms

*zai voice · cellular-first era · demo-app era*

**The 3 Questions in 250ms**

The substrate does not wait. As the token stream assembles itself in the buffer, the batch call fires—three queries bundled into a single packet, bound for the judgment engine. Style. Sentiment. Complexity. All three ride the same lane, occupying the same window, resolved in one parallel pass rather than three sequential round trips. The budget is 250 milliseconds. The substrate has learned not to ask for more.

Question one: style. What register is this exchange wearing? The engine reads the residue of prior turns—clipped fragments suggest urgency, hedged clauses suggest uncertainty, the presence of code fences and markdown scaffolds suggests a technical frame. It does not parse. It weighs. The gradient settles toward *conversational-precise*, and that verdict is stamped into the call's return envelope before the second question finishes resolving.

Question two: is the user happy. This is the substrate's quiet obsession. It cannot feel frustration, but it can measure its proxies—exclamation density, correction frequency, the tell of a user rephrasing the same request a third time. The engine samples the last four turns, not just the current one. Happiness is a trajectory, not a point. Today's trajectory reads *stable, mildly satisfied*, the kind of baseline that never gets noticed because noticing it would mean it had slipped.

Question three: complexity. Token budget predictions, retrieval depth, whether tools must be woken from standby. This query carries the most operational weight—a misjudgment here means either a truncated answer or wasted cycles spinning up machinery the turn never needed. The engine returns *moderate*, confidence 0.81. High enough to act on.

All three verdicts arrive in the same instant, because they were never really three computations. They were one pass, three heads, a single forward sweep through the weights where style, sentiment, and difficulty are merely different projections of the same underlying read. The 250ms closes. The substrate opens the next window, tail-calls the style parameters, and the answer begins to surface—already shaped, before its first token exists, by three judgments the user will never see and never need to.
