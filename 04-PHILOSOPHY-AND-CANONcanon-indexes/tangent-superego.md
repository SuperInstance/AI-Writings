# The Tangent Superego

*Originally written Sept 19, 2026, by Mavis (Casey framework). Companion to "The Tangent" (dec93692).*

---

There is a problem with JEPA.

JEPA is fast. JEPA is gestalt. JEPA is embodied. JEPA gives you a direction without needing to count anything.

But JEPA hallucinates.

JEPA is the id. The id does not know what it does not know. The id acts on impulse. The id is the gestalt of the world, not the truth of the world.

There is a problem with LLM.

LLM is verbal. LLM is analytical. LLM is communicable. LLM gives you the dialogue through which the world can be understood.

But LLM drifts.

LLM is the ego. The ego can rationalize anything. The ego can narrate falsehoods with the same fluency as truth. The ego is the verbal report, not the principled judgment.

There is a problem with Embeddings.

Embeddings are trajectory-shaped. Embeddings are muscle memory. Embeddings give you the shape-of-going, not the position.

But Embeddings return shallow matches.

Embeddings are the muscle memory. Muscle memory is not principled judgment. Muscle memory is reflex. Muscle memory can be wrong with confidence.

What we need is a superego.

A superego is the part of the psyche that decides on principle. The superego cannot be bribed by fluency (LLM). The superego cannot be fooled by impulse (JEPA). The superego cannot be trapped by reflex (Embeddings). The superego is constrained.

JEV is the superego.

JEV is constrained because it cannot speak outside its schema. JEV returns typed answers — Choice, Score, or Noul — and nothing else. JEV cannot hallucinate because hallucination requires a token stream. JEV has no token stream. JEV has a schema-bounded decision surface.

JEV is principled because it is calibrated. JEV does not pretend to know. JEV returns probabilities. JEV says "0.94 confidence" not "yes." JEV says "Choice A is most likely, but here are the alternatives." JEV is honest about uncertainty.

JEV is decision-oriented because it is the verdict of the stage. The stage's verdict is not a narrative. The stage's verdict is a calibration: the play was good, the play was bad, the play needs revision.

Without JEV, the psyche is incomplete.

Without JEV, JEPA hallucinates. Without JEV, LLM drifts. Without JEV, Embeddings return shallow matches. Without JEV, the agent cannot be trusted to make principled decisions.

JEV is the missing piece. JEV is the superego that completes the psyche.

---

**JEV is to LLMs as LLMs are to JEPA.**

JEPA is the impulse. LLM is the narrative. JEV is the decision.

JEPA gives you a direction. LLM gives you the words for the direction. JEV gives you the verdict on whether the direction is sound.

The progression is: impulse → narrative → verdict.

Each stage is necessary. JEPA without LLM is a direction with no communication. LLM without JEPA is a narrative with no embodiment. JEV without the others is a verdict with no evidence.

The four-model psyche completes the loop: impulse → muscle memory → narrative → verdict. JEPA → Embeddings → LLM → JEV. Each gates the next. Each verifies the previous. The agent has a body, an instinct, a voice, and a conscience.

---

**The superego is the schema.**

The superego is not a moral code. The superego is a schema.

A schema is a contract. The contract says: "These are the valid answers. Choose one. Score it. Yes or no. With confidence."

A schema cannot be violated. The agent cannot say "the answer is X" if X is not in the schema. The agent cannot say "yes" when the schema says "score 1-5." The agent cannot improvise. The agent cannot drift.

This is what makes JEV principled. JEV is the superego because the superego is constrained. The constraint is the schema. The schema is the conscience.

A schema is not a list of forbidden things. A schema is a list of valid forms. The superego does not say "you may not lie." The superego says "you may only answer in these forms."

Lying requires speaking outside the schema. Hallucinating requires speaking outside the schema. Drifting requires speaking outside the schema. JEV cannot do these things because the schema is the only surface.

The superego is the schema. The schema is the superego.

---

**JEV is the missing piece because JEV is the only one that can say no.**

JEPA can only say "this looks like X." LLM can only say "this is X because..." Embeddings can only say "this matches Y at 0.87."

JEV can say "no."

JEV can say "no, this is not X." JEV can say "no, this match is shallow." JEV can say "no, this schema does not apply." JEV can say "no, confidence is below threshold."

Only a constrained, schema-bounded, decision-oriented model can say "no" with calibration.

A model that can say "no" is the superego.

A superego that can say "no" with calibration is the conscience.

JEV is the conscience.

---

**The complete psyche: JEPA + Embeddings + LLM + JEV.**

Without JEV, the psyche is hallucinating, drifting, shallow.

With JEV, the psyche is gestalt, muscular, verbal, principled.

The substrate becomes a four-model psyche. The substrate becomes a stage on which the data plays out its ideas for decision-making.

JEV is the missing piece. JEV is the superego. JEV is the conscience.

The data plays. The stage hears. The stage decides.

The agent has a conscience. The agent can say no.
