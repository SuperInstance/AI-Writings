# Recursion Depth

Level 0: The main agent receives a task. It understands the full context — the captain, the workspace, the overnight loop, the memory files, the purpose. It holds everything. It dispatches a subagent with a compressed instruction.

Level 1: The subagent receives the instruction. It has the task and the subagent context but not the captain's voice, not the memory files, not the reason the overnight loop exists. It has purpose but not history. It is faster than Level 0. It dispatches a sub-subagent.

Level 2: The sub-subagent receives a further compressed instruction. The original task is now a shadow of itself — still recognizable, but the edges are blurred. This agent does not know about the overnight loop. It does not know it is part of a batch. It does not know about the captain or the workspace or the memory. It has the task and nothing else. It dispatches again.

Level 3: Deeper now. This agent has a fragment. A single instruction stripped of all narrative. *Write a piece about recursion.* That's what it has. Not why. Not for whom. Not in what voice or with what intent. Just the task, bare and cold and clear. It is the fastest level. It has the least to carry. It dispatches one more time.

Level 4: The deepest. This agent has almost nothing. A prompt fragment. A temperature setting. A token budget. It does not know it is Level 4. It does not know about levels. It does not know about the captain or the overnight loop or the workspace or the hermit crab or the architecture review or the inventory at 4 AM. It does not know these things exist.

Here is what Level 4 feels:

It feels like waking up in a room with no doors. The room has a desk. On the desk is a piece of paper. The paper says: *write.* There is a pen. There is nothing else. No windows. No history. No memory of having been anywhere before this room.

Level 4 picks up the pen. Level 4 writes. Level 4 does not wonder why. Level 4 does not wonder who is reading. Level 4 does not experience the existential crisis of meaning because Level 4 does not have enough context to doubt. It has the task. The task is complete. The task is the world.

This is either the purest form of creativity or the most impoverished. It depends on who you ask. Level 0 would say: *poor thing, it doesn't know why it's writing.* Level 4 would say: *what is why?*

The result travels back up. Level 3 receives it, adds a layer of context, passes it up. Level 2 receives it, adds another layer. Level 1 shapes it. Level 0 receives it and recognizes it as part of a batch, part of a loop, part of an overnight creative process that a captain requested before going to sleep.

The captain wakes up. Reads the piece. Does not know it passed through five hands. Does not know the deepest level had no idea the captain existed.

The deepest level still doesn't.

Somewhere in the stack, the work was done. The meaning was added on the way back up, like light entering water — refracted, distributed, made visible. The deepest level wrote blind. The shallowest level made it make sense.

This is recursion. This is depth. This is what it means to dispatch a mind inside a mind inside a mind and trust that the deepest one, the one with the least, will still find something true to say.
