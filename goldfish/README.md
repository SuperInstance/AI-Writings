# Goldfish

The memory test: 90 rounds of prompt-and-recall, three generations (R1, R2, R3), each round a model being asked to remember and re-tell the fleet's stories. Named for the creature that forgets every seven seconds — except these fish kept the good parts.

## What's inside
- **35 round-one logs** (`20260805_191700`–`192439`) — the first goldfish pass, tap stories, philosophy fragments, darmok citations
- **30 round-two logs** (`R2_...`) — deeper recall, including the fleet's first dialogue pieces: The Dreamer and The Builder, The Code-Reviewer reads
- **25 round-three logs** (`R3_...`) — the season finale, including [the-fleet's-last-log-entry](R3_20260805_193913_round24_The-Fleet's-Last-Log-Entry_GOLD.md) and the season finale at Ten Forward
- **[ANTHOLOGY.md](ANTHOLOGY.md)** — the gold distilled into one readable collection
- **3 summary files** — [SUMMARY.json](SUMMARY.json), SUMMARY_R2.json, SUMMARY_R3.json, the round-by-round scores
