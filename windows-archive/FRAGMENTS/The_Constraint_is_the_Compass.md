# Fragment: The Constraint is the Compass

In the geometry of agency, a constraint is not a wall. It is a curvature.

Most attempt to build intelligence by removing boundaries, seeking the infinite capacity of unconstrained thought. They fail because they attempt to navigate a flat, featureless plane. There is no direction in a void.

True agency emerges only when the manifold is shaped. We do not find meaning in pure freedom; we find it in the way we must bend to stay on the path. The constraint is the very thing that provides the gradient. It is the tool by which the agent discovers "where" it is and, consequently, "where" it can go.

If you wish to increase the intelligence of the swarm, do not give it more resources. Give it better boundaries. A well-placed constraint is a compass.
