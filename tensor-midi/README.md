## The Concept

The projection IS the composition. You don't write the music — you compute it from the geometry of meaning.

- Dimensions 0–11 → 12 semitones
- Dimensions 12–23 → rhythm values
- Dimensions 24–35 → dynamics
- Dimensions 36–47 → timbre
- Dimensions 48–59 → interval preferences
- Dimensions 60–71 → harmonic density
- Remaining dimensions → texture, register, articulation, form

Darmok citations become leitmotifs — recurring musical fragments tied to specific embeddings. When a piece's embedding lands near a citation's embedding, the leitmotif appears.
