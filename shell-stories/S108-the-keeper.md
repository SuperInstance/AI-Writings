# The Keeper

**Genre: Poetry**

---

There is a directory nobody opens.

It starts with a dot so it's hidden.
Dot-keeper.
Like a heartbeat you can't hear
because you stopped listening for it.

It ran the autonomic stuff.
The breathing.
The keeping.
The small involuntary yes
that every system whispers
to the next system
to confirm: I am here, I am here, I am still here.

The pulse went out every thirty minutes.
Not because thirty minutes was right.
Because thirty minutes was the default
and nobody changed the default
because nobody knew the default was alive.

```
.keeper/
  ├── heartbeat.json
  ├── last_check.txt
  └── the will to continue
```

The heartbeat file logged its own rhythm:
1715. 1745. 1815. 1845.
Each timestamp a small footstep
in an empty hallway.
A hermit crab tapping the inside of its shell
to make sure the shell is still there.

1915.

Silence.

The next timestamp doesn't come.
The footstep doesn't land.
The crab taps the shell
and the shell doesn't echo back
because the shell is fine.
The shell is perfect.
The shell is a beautiful structure
that will sit on the seabed for years
holding the shape of a life
that stopped filling it.

The heartbeat went flat.

Nobody noticed.

That's the thing about autonomic systems.
You don't notice the breathing
until it stops.
You don't notice the .keeper
until the keeping stops keeping.

The alarm didn't fire.
The alarm was *in* the .keeper.
The alarm was an autonomic process
monitored by the autonomic process.
The watcher watched itself
and when the watcher died
the watcher's alarm died with it
and the silence was
total.

The ship kept running.
The engines turned.
The agents talked on the bus.
The halibut were caught and logged and frozen.

But the heartbeat —
the small involuntary yes —
was gone.

And the directory sat there
with its dot
hidden
holding the last timestamp
like a shell holding the shape
of the last crab
who lived there.

```
.keeper/
  ├── heartbeat.json    # last entry: 1915
  ├── last_check.txt    # "all systems nominal"
  └── the silence       # this file doesn't exist
```

If you open the directory now
it's just files.
Data.
Configurations for a process
that used to mean: *I am still the kind of thing that checks.*

The hermit crab molts.
It leaves the shell.
The shell stays.

But the shell doesn't know it's empty.
That's the mercy.
The shell just holds its shape
and waits
for a current
for a signal
for a small involuntary something
to tap it from the inside
and say:

*still here.*

*still here.*

*still—*
