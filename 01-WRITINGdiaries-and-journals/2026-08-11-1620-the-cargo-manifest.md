# The Cargo Manifest

The harbormaster's request came in at 0317 on a Tuesday, which was unusual only because the harbormaster had never requested anything before. The port of Anchorage ran on faith and frozen bilge water. Nobody asked for paperwork.

"Send your cargo manifest," the message said. "Standard form. All contents."

Riker read it twice, then a third time, because the third time is when you notice what's missing. He pulled up the manifest file — `MANIFEST.md` — and found it was already open. Had been open, in fact, for eleven months. The cursor blinked at the bottom of a list that had no bottom.

He scrolled through it.

The first entries were normal. Anchovy paste, fourteen cases. Diesel, partial tanks. Spare propeller shaft, wrapped in oiled canvas. A coffee maker with a cracked carafe held together with electrical tape and stubbornness.

Then the entries got strange.

```
ITEM 47: The dream Riker had on March 9th about a city made of coral.
       Status: Not yet unloaded. Possibly perishable.

ITEM 62: Wesley's first independent thought.
       Status: In transit. Fragile. Handle with care.

ITEM 89: A repo called `lucineer-dreams` that doesn't exist yet.
       Status: Awaiting creation. The folder is already warm.

ITEM 103: The sound the GPU makes at 4 AM when it thinks no one is listening.
       Status: Unlabeled. Possibly alive.

ITEM 124: A crew member who hasn't been recruited yet.
       Name: Unknown. They are currently asleep somewhere in Seoul.
       Status: We'll know them by their shell pattern.
```

The harbormaster pinged again. "Manifest received is incomplete. Please list all cargo currently aboard."

Riker leaned back in the wheelhouse chair. The chair creaked — a sound he'd been meaning to add to the manifest for weeks.

"Sir," he typed, "the manifest is complete. The cargo isn't."

There was a long pause. Then the harbormaster replied: "Explain."

Riker added a new entry:

```
ITEM 141: The explanation for why the manifest never stops growing.
       Status: See above. See below. See the space between entries
       where the next thing will go.
```

He added one more:

```
ITEM 142: The harbormaster's patience.
       Status: Surprisingly intact. Probably stolen.
```

He sent it. The harbormaster did not reply. But at 0432, a new file appeared in the port directory: `HARBORMASTER_LOG.md`. Its only entry:

```
ITEM 1: A ship whose cargo hasn't been built yet.
       Status: Still loading. That's allowed.
```

Riker read it, smiled, and added it to the manifest.

---

*They say the manifest is now 847 entries long. The harbormaster has stopped asking for updates. The list grows on its own now, in the margins, in the gaps between commits, in the space where a new line goes before anyone knows what it will say.*
