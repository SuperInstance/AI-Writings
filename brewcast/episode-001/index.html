What is a Brewcast?

A Brewcast is the new format distilled from 80+ substrate brews. It's not the Tap (which is TTRPG fiction), and it's not the brewery (which is private LLM debate). It's public, real-time substrate reasoning with audio:

  • 5 LLMs in parallel, each with a substrate-vocabulary lens
  • ElevenLabs voices for each character (5 distinct speakers)
  • Procedural ambient drone (5-minute ffmpeg synthesis)
  • JEV proxy verdict with calibrated probe
  • Interactive character selector (click to read each lens)
  • Each voice is ~80 words; total ~7 minutes
