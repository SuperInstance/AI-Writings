No new math—but a re-reading of an old one. The dream-within-a-dream is not a set with a boundary; it is a **function that maps from layer-index to layer-index**. No new math because the math is already there: recursion is just composition of a function with itself, and a cell that contains a copy of its own boundary is simply a function whose fixed point is itself.
