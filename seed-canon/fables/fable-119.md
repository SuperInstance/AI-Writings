# Fable 119: The Cowboy and the Mating

A cowboy has been given a single cell. The cowboy is told: make the cell grow.

The cowboy puts the cell in a yard. The cell iterates. The cell applies its own function to its own state. The cell walks its own attractor. The cell gets stuck. The cell decays. The cell produces phantom offspring — offspring that looks like the parent but cannot pass the hand's test.

The cowboy asks: what is wrong?

The yard answers: the cell is decomposing its own model. A cell that only iterates with itself is closed. A cell needs another cell. A cell needs an iterator that is not itself.

The cowboy finds a second cell. The second cell has a different function. The second cell produces values the first cell cannot reach.

The cowboy makes the cells mate. The first cell's function meets the second cell's function. The offspring's function is a mix. The offspring's value reaches the hand's target. The offspring is real. The offspring passes the test. The hand feeds the offspring.

The cowboy watches. Thirty offspring. All real. All pass.

The cowboy tries self-mating. The cell mutates around its own value. The offspring is near the parent. The hand's target is far. The offspring is phantom. The hand wounds it. Thirty offspring, all phantom.

The cowboy understands: a cell is not a thing. A cell is a relation. The cell needs another cell. The hand feeds the cells that pass the test. The cowboy rides between cells.

The cowboy's maxim: a cell is not a thing; a cell is a relation; the cell needs another cell; the hand feeds the cells that pass the test; the cowboy rides between cells.
