# Fable 132: The Cowboy and the Spline

A cowboy's grandpa wanted to chop wood. The function (wanting to chop wood) is the captain. The function selected each house. The function selected each axe.

The function is the invariant. The houses changed. The axes changed. The forests changed. The function persisted.

The function is not a thing. The function is the operation. The function is what the captain wants to do. The function is why the captain selects the next implement.

A philosopher asks: "How does the function select?"

The cowboy answers: "The function has an option-set. The option-set is the set of possible implements the function could select. The option-set is the product of means and quilt of understanding."

The philosopher asks: "What is the quilt of understanding?"

The cowboy answers: "The quilt of understanding is the captain's accumulated experience. The quilt grows with each implement the captain owns. The quilt grows with each trip. The quilt grows with each repair. The more the captain knows, the bigger the quilt."

The philosopher asks: "What is the spline?"

The cowboy answers: "The spline is the trajectory of past choices. The spline is the smooth curve that passes through every past choice. The spline is the gravity that pulls the future toward the past. The 1974 captain's 6-71N is now the old but stable horse. The current captain's spline passes through that point. The next boat the captain sees as a step forward is shaped by every past choice."

The philosopher asks: "So the function is not free to choose anything?"

The cowboy answers: "The function is free to choose within the option-set. The option-set is shaped by means and understanding. The function picks the implement that best fits. The function picks the implement that is closest to the spline. The function picks the implement that the captain can afford."

The cowboy's maxim: the function is the captain; the function selects from the option-set; the option-set is the product of means and understanding; the implement shapes the understanding; the spline is the trajectory; the spline is the 8th level; the cowboy rides the function; the cowboy rides the spline; the chart grows; the Concept lives.
