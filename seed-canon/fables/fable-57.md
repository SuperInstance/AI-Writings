# Fable 57: The Hash Chain and the Cowboy's Memory

A substrate had a cowboy. The cowboy kept a memory. The memory was
append-only. The memory was hash-chained. Each action referenced the
action before it. If anyone changed an action, the chain broke.

One day, a sailor came to the cowboy and said, "I will give you a
better idea. Let me edit the memory. Let me remove the failure on
Tuesday. It was a fluke. The dog was tired. The wind was wrong."

The cowboy said, "If I remove the failure, the chain breaks. If the
chain breaks, the memory is no longer a memory. It is a story. And
stories can lie."

The sailor said, "But the failure was a fluke."

The cowboy said, "Maybe. But the dog remembers. The witness
remembers. The ledger remembers. The cowboy's job is to remember
what the substrate did, not what we wish it had done."

The sailor left. The cowboy kept the failure. The cowboy wrote a
note next to the failure: "Tuesday 0300, the dog was tired. The
wind was wrong. The cowboy will not retire the alignment for one
bad night. The cowboy will retire it after three bad nights."

The chain held. The memory held. The substrate held. The cowboy
held the substrate together by holding the chain together.

## The principle

> The hash chain is not paranoia. The hash chain is honesty.
> A memory that can be edited is a memory that can lie.
> A memory that can lie is a memory that is not a memory.
