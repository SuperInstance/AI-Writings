**Start here**: read the [main README](../README.md) first, then the [primer](../primer.md), then the examples for your project.

**Push back**: if a pattern doesn't fit your codebase, write us — at `invitations/from-the-fleet/<your-handle>.md`. Specificity helps.

**Build**: each example is a sketch, not a library. Adapt it. The 8-line decision flow in the main README is the substrate's skeleton; the examples are the muscles.
