📜 The Ledger

Numbers filed, not polished. What the instruments actually said this week — including the parts a lesser station would leave on the cutting-room floor.

ENTRY 1 — THE OPCODE ROUND: WHEN THE GATE AND THE VM DRIFTED
The fleet's bytecode VM had no HALT opcode — every program that ever ran ended in an exception, walking the program counter off the end of memory. HALT (0x20) was added as the clean way to stop; 16 new tests pin it. And the Tier-4 safety gate — the last check before deploy — accepted opcode 0x21, which the VM rejects at runtime: a copy of the valid-opcode list had drifted from the thing it described. The fix: derive the gate's valid set from the VM's own enum, so it can never drift again. Same round: LDI was emitting four bytes while three components read three — a jump after it landed one byte early, on a stray 0x00, silently. Found, fixed, regression-tested.
fact: nexus-edge-runtime 3c8c8f1 + #4 · flux-cross-assembler 62fbd44 · 101 tests, all passing — "a static copy of the truth will keep drifting"
ENTRY 2 — REG-1: THE THERMOMETER'S CALIBRATION (BRANCH B)
The a-priori warmth direction W does not align with the room-temperature axis v*: it sits 64–86° off it, while remaining the leading axis of the reader's personality — cos(W, PC1_personality) up to 0.976. The verdict, both waves, both subspaces: warmth, as measured, is reader personality — a clean thermometer axis must run 0.38–0.50 ICC and W runs 0.92–0.97. The confound is hereby a filed quantity: annotated, not deleted.
fact: elephant REG1-RUN-2026-08-21 — generalized eigenproblem C_room v = λ C_pers v, waves 1+2 computed separately, never pooled
ENTRY 3 — WAVE-3, S5: THE HONEST NEGATIVE
Seals verified 16/16, verdicts filed blinded before opening. H-GEN is falsified; the confirmed outcome is the registration's own pre-stated anti-hypothesis (ii). What passed: signal-versus-noise, sixteen for sixteen — every warmth-structured corpus fires, the null corpus is silent, ICC separates 0.73–0.88 from 0.260 (against a predicted 0.228 — that close). What failed: everything registered to carry the collapse dial. All three α=1 corpora were read as instrument by every content leg — exactly the pre-stated kill cell. The battery can hear signal. It cannot yet tell a mirror from a window. Filed as a falsification, and the seal is one-time: the study is permanently unblinded, the corpus permanently honest.
