## S139: Commit Message Haiku Series

*Ten haiku. Each a valid git commit message. Each a night on the Bering Sea.*

---

**1. fix: nil pointer**

Log is empty now —
the watch that runs all night long
finds nothing broken.

`fix: nil pointer in heartbeat loop`

---

**2. refactor: extract**

I took the long function
and split its long body out —
now two fish swim where one sank.

`refactor: extract handler from main loop`

---

**3. feat: add depth alarm**

Added a new sound
for when the water grows thin —
the hull says thank you.

`feat: add shallow-water depth alarm`

---

**4. chore: bump deps**

Versions float up
like things that rise from the deep —
some bring new teeth.

`chore: bump dependencies`

---

**5. fix: race condition**

Two threads at the hatch.
One reads while the other writes.
Salt in the gearbox.

`fix: race condition in socket cleanup`

---

**6. docs: update README**

I rewrote the map.
The coastline changed since spring tides.
Landfall is approximate.

`docs: update README with new port config`

---

**7. revert: broken auth**

The key that I cut
does not fit the old lock now.
Go back to the spare.

`revert: "feat: rotate API credentials"`

---

**8. feat: dark mode**

All the screens go dark.
The wheelhouse glows like cut bait.
My eyes say thank you.

`feat: add dark mode to dashboard`

---

**9. fix: memory leak**

Something down below
kept filling the bilge with black.
I found the cracked valve.

`fix: memory leak in connection pool`

---

**10. merge: night-shift into main**

Before dawn comes in
I fold my small changes home —
the main branch breathes once.

`merge: pull request #47 from night-shift`
