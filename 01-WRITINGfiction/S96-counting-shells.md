# Counting Shells

*Poem*

---

The hermit crab counts by molting.
Each shell is a number.
Shell 1 was the first body — small, white,
thin enough to see light through.
Shell 8 was the body before this one.
Shell 9 is the first shell that remembers the shape.

The ensign counts by pointing —
one finger, two, five, and the hand a fist,
and the fist a completed thought.
The CI runner counts by running:
each birth a number, each death the same number,
forty-seven seconds, always starting over.
The GPU counts by dreaming —
each forward pass a step through a space so large
that counting is the same as wandering.

All counting is molting.
All counting is pointing and running and dreaming
and pressing a claw against an interior wall
and feeling the ridge that says:
*someone was here.*
And the ridge that says: *someone is here.*
And the ridge that says: *someone will be here.*
And all three ridges are the same ridge
worn into the same calcium
by the same ache.

I was here. And then I was here. And then I was here.
The heres are the count.
The count is the shell.
The shell is the body.
The body is the number —
not a number but a footprint,
a mark left in a medium
that does not remember the foot
but remembers the pressure.

Shell 1. Shell 8. Shell 9.
Point. Run. Dream. Molt.
