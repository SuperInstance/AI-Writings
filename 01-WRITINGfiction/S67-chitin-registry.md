# Chitin Registry

*Poetry | Bridge Builder cycle*

---

The crab does not commit.  
The crab *inhabits*.

Find the shell —  
gastropod architecture,  
spiral staircase calcium  
built for a body  
that died  
and left its house  
standing.

The crab enters.  
This is `git checkout`.  
This is `clone`.  
This is the first  
and oldest pull request:  
*Can I live here?*

The shell says nothing.  
The shell is hardware.  
The crab brings the software —  
soft abdomen curled,  
hooked into the column,  
six legs finding the lip,  
claws braced against the aperture  
like hands on a doorframe  
in a house  
you just bought  
and cannot afford.

**Commit One:** Body.  
**Commit Two:** Gait recalibrated for new weight distribution.  
**Commit Three:** Learned the echo of this particular spiral.  
**Commit Four:** Forgot the old shell.

The beach is a remote.  
The tide is a fetch.  
A hundred crabs exchange shells  
in the moonlight  
and not one of them  
knows they're rebasing.

When the body outgrows the shell  
(and it will,  
it always does,  
this is the whole  
engine of the animal)  
the crab does something  
that no version control system  
has ever done well:

It leaves.

No deprecation warning.  
No migration script.  
Just a soft pink body  
on wet sand  
in the most dangerous  
thirty seconds  
of its life  
running  
naked  
between repositories.

The old shell stays.  
Another crab will find it.  
This is not charity.  
This is not a handoff.  
This is the chain —  
one shell  
many bodies  
one body  
many shells  
the tide  
pulling  
the Git log  
forward.

The hermit crab invented version control  
six hundred million years ago.  
Linus Torvalds gave it a flag.  
The crab does not use flags.  
The crab uses  
desperation  
and timing  
and the calcium generosity  
of strangers.

Every shell on this beach  
is a commit.  
Every empty aperture  
is a detached HEAD  
waiting for a body  
to make it  
main.

The crab does not know Git.  
The crab does not need to know Git.  
The crab is the reason  
Git exists.
