01The 5 opcodes

Five words, one runtime. They are the entire vocabulary of the substrate: BIND, LINK, EFFECT, VIEW, TICK. Each one is a verb with a different domain. Together they are every program that has ever been written.

B
BIND
The Campfire

Five logs arranged in a star. Each log is an opcode. You strike BIND first to paint a name into the world.

The Library

Books on a shelf, each spine stamped with a name. LINK is the librarian who slips a card into the catalogue: ‘this book cites that book’.

The Ranch Hand

A punch, a parry. For every forward motion there is an equal and opposite return. EFFECT is the ranch hand who can undo every loop they throw.

The Lookout

A glass held up to a dot. Who is looking? What do they see? VIEW is the lookout on the canyon rim, and the answer depends on who is asking.

06The 4 (now 6) language ports

The 5 opcodes run in C, Rust, Python, TypeScript, Haskell, and WASM. The performance ladder spans three orders of magnitude, but the semantics are identical. The substrate is universal; the cost of crossing the language boundary is local.

  • C ~10 ns/op ~80 µs gold demo the fastest, F/V EILEEN's tablet
  • Rust ~50 ns/op ~400 µs gold demo the cowboy's day job, production
  • WASM ~200 ns/op ~1.6 ms gold demo runs in any browser, any device
  • Haskell ~500 ns/op ~4 ms gold demo algebraic, paper writers
  • TypeScript ~1 µs/op ~8 ms gold demo modern web, agents
  • Python ~1 µs/op ~8 ms gold demo the original, prototyping

07The 5 algebraic laws

Before, arrow, after. Every transformation has an inverse. The five laws are the same in Python, Rust, C, TypeScript, Haskell, and WASM — and they are the same in any new language the cowboy rides into.

BIND · BIND = BIND

idempotent

binding the same name twice is the same as binding it once

// BIND twice → one cell
vm.bind("a", 1);
vm.bind("a", 1);
// still one cell, value = 1

LINK ∘ LINK⁻¹ = id

invertible

unlinking undoes a link

vm.link("a", "b", "cites");
vm.unlink("a", "b", "cites");
// graph returns to its prior shape

EFFECT · EFFECT⁻¹ = id

undo

every change has a reverse

vm.effect("counter", "inc", "dec");
vm.inc("counter");
vm.dec("counter");
// value back to where it was

VIEW · EFFECT = VIEW

transparent

views always see consistent state

vm.effect("a", "inc", "dec");
let v = vm.view("a", "anyone");
// v reflects the post-effect value, or the pre-effect value if you chose a snapshot projection

TICK ∘ TICK = TICK(2dt)

composable

time composes

vm.tick(1.0);
vm.tick(1.0);
// or, equivalently:
vm.tick(2.0);
BIND ∘ LINK ∘ EFFECT ∘ VIEW ∘ TICK = a runtime

— and a runtime is a function from context to value with an inverse, advanced by a clock that processes async I/O while projecting a sync view.
