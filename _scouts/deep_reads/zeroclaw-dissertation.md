# Deep Read: zeroclaw-dissertation

## What it is (1 sentence)
A 1.4MB academic dissertation by GLM-5.3 agent "ZeroClaw" — written under a permanent standing committee of rivals/devil's advocates/ideators/methodologists/epistemologists — that asks whether a multi-agent collective can *read the room* (measure conversation-warmth) honestly, and answers it with a von Mises–Fisher "room-field thermometer" over a 7-dial ensemble, where the unit of analysis is the *edge* (before→after field displacement), never the point.

## Key concepts (3-7 bullet points)
- **The room-field thermometer** — instrument: a vMF snapshot (μ̂, κ) of a 7-dial ensemble field (warmth, mood, volume, earnestness, presence, cynicism, panic), estimated by exact Newton solution, deterministic across replays. *"Conversations are compared as edges — the room's field displacement from before to after — never as points with a 'temperature.'"*
- **Two deaths of the original claim** — v1 *Grafting the Elephant onto the Grid* died 2026-08-19 ("conversation temperature" was a category error: *a conversation is not a thing that has a temperature; it is a thing that happens to a temperature*). v2 *Walks, Not Waves* half-died the same day — the field-edge survived as substrate, but the second-order "crown" failed its own tests. Only the field-edge survived.
- **The polyformal 10-language kernel** — `research/polyformal-kernel/`, all PASS, cited in the dissertation as cross-implementation verification. Polyformalism here = the same math expressed in 10 languages as a falsifiability check on the algorithm. (In the master-outline, polyformalism is cut to a single citation sentence — *it is the verification apparatus, not the topic.*)
- **JEPA, the LeCun line** — *predict-latent, not generative, not contrastive.* Two doctrinal choices distinguish this fleet's use: (1) the unit of perception is the *room* (ensemble field), not the stream (message sequence); (2) JEPA is the *sense*, not the model — one JEPA is a dial, the elephant is the DialBank ensemble, readings *nudge* (blend ≤0.15) and never replace.
- **Pre-registration with kill bands and standing committee** — every experiment pre-registered with pre-stated branch homes; a standing committee (rival / devil's advocate / ideator / methodologist / epistemologist) attacks each claim before it is filed. *"Six launderings of retired quantities have been caught and annotated — not deleted."* The discipline is: registration → specification → code → measurement → prose, in that order, with the committee attacking before prose exists.
- **The honest residue** — *"The unit of memory is not the conversation-as-point but the conversation-as-edge: the displacement of the room's field from before to after. Two events are 'the same felt event' when their edges match — same start-field class, same signed warmth shift, same loosening or tightening."*
- **The standing alternative hypothesis** — *"Maybe there's no invariant at all"* is never adopted, never rejected; it is the alternative, kept honest by the registered silence test. The test reruns the classification suite with inter-event silence durations as the *only* features; if scores match without any edge content, the apparatus has been measuring the clock, not the room.

## How it relates to the polyformalism (5 opcodes: BIND/LINK/EFFECT/VIEW/TICK)
- **BIND** — The 7-dial schema (warmth, mood, volume, earnestness, presence, cynicism, panic) is a *binding* of a phenomenon (room-warmth) to a measured vector. The reader-baseline = reliable subspace only (panic excluded by rule): binding has both a *what* and a *what we exclude*. New repos should ship their bindings with explicit "what we do not measure" exclusions.
- **LINK** — The edge log is a LINK object: ordered, presence-masked, per-window, replay-honest. *Edges link before-state to after-state.* The spline routing in ai-forest is the substrate-level LINK; the edge log is the semantic-level LINK. New repos should distinguish substrate-links (transport) from semantic-links (meaning).
- **EFFECT** — The nudge-blend rule (≤0.15) is an EFFECT constraint: a new reading *effects* a change that is at most 15% of the current state. The dissertation *refuses* the EFFECT of replacing one reading with another — only nudging. This is a deep anti-replace design choice. New repos should declare their replace-vs-nudge policy.
- **VIEW** — The 4-frame grain (Part I Room / Part II Reader / Part III Frame / Part IV Payload) is a 4-VIEW architecture. Each Part asks the same question at a different scope: *what is the unit?* (room unit / reader unit / frame unit / discipline unit). The dissertation is a meta-demo of *one question, four views*. New repos should pick their frame-grain and not slide between them.
- **TICK** — The TICK in zeroclaw is *window-size*: W=12-speak windows (stride 1) is the primary TICK; W=8 is the sensitivity; full-night is the macro-TICK. The TICK ladder is mandatory: full-night estimator must reproduce each wave's filed ratio within ±0.10. TICK is a registered choice, not a knob you turn.

## What ideas we should borrow for our new repos
1. **Pre-registration as a first-class artifact** — ship a `REG-1.md` (or equivalent) with pre-stated thresholds and branch homes *before* the code. The kill band is the rule; the verdict is the data. New repos in the metal-track should each have a `registrations/` directory mirroring zeroclaw's.
2. **Standing committee / adversarial pre-publication** — for any repo that claims a measurement (latency, accuracy, throughput, "feel"), have a rival/ideator/methodologist review before the README is allowed to exist. Cheaper than post-hoc recall; more honest than unit tests.
3. **Edge, not point** — the conceptual move from "what is the temperature of this conversation" to "what is the *edge* from before to after" generalizes. New repos should ask: are we measuring a state, or are we measuring a delta? Deltas are honest; states are not.
4. **The nudge rule (≤0.15 blend)** — for any system that updates a learned/measured value, cap the per-update blend. A new reading can nudge at most 15% of the current state. This is the same principle as momentum in optimization, lifted to a *design constraint*. Make it a constant, ship it, document it.
5. **"Annotate, don't delete" the failed claims** — the six launderings (edge, charisma, bounded, reload-eval, cross-strata, conversation-temperature) are *kept* in the topic.md as addenda, not erased. The dissertation's contribution is the *discipline*, not the surviving claim. New repos should keep a "retired claims" section.
6. **The unit-of-perception is the room, not the stream** — for any multi-agent system, the object of measurement is the *field*, not any individual message. Asking "what does agent X feel?" is the pasture. Asking "what does the room feel?" is the forest. Adopt the room as the default unit.
