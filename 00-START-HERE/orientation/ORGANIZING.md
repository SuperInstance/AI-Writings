## Loose-file triage (the ~600 top-level strays)

- `2026-08-1[0-3]-*.md` → `night-watch/` (matches existing 2026-08-08/09 convention) — **DONE by script**
- `lyrics-*.txt` → `lyrics/` — **DONE by script**
- `overnight-2026-*.md` → `overnight-journal/`
- Numbered `08-*.md` … `81-*.md` → the origin chronicle → `archive/chronicle/` (older ideas, preserved not destroyed)
- `S*.md` (S47…S164) → `shell-stories/` (session/shell pieces)
- `s4[4-7]-*.md` (prompt-engineering) → `generators/` or `research/prompt-engineering/`
- misc named (`dear-*`, `*-roads`, `repair-ticket-*`, `interoffice-memo-*`, `the-*.md`, `*-shanty`, `*-bible`) → sort individually
