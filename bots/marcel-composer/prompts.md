**Description**: **Substrate** is a work of glitchy electronica built around the architecture of decision-making. Granular textures fragment and reassemble like data packets rerouting through a compromised system, while micro-edits—stutters, dropouts, bit-crushed artifacts—evoke the audible friction of computation under scrutiny.

The piece maps JEV-style decision moments: sudden fork points where a clean melodic line abruptly splits into competing variants, each rendered in slightly detuned parallel layers before one resolves and the others dissolve into static. Fast decisions arrive as percussive bursts—hi-hats firing in algorithmic clusters, snapshots of snap judgment—while slow decisions unfold as glacial pad swells, drones that deliberate across minutes, bending pitch as if weighing outcomes.

Underneath it all run audit cycles: periodic rhythmic loops that return like scheduled verifications, each pass subtly degraded or corrected, revealing whether the system's earlier choices held or eroded. The result is accountability rendered as sound—procedural, nervous, strangely human in its indecision.
