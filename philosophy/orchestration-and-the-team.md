# Orchestration and the Team

*Posted September 18, 2026. When the lattice grows, the agent team grows.*

---

The lattice has 50 production tests, 10 cell kinds, 147+ canon pieces, 600+ shelves. Building it serially would take 100 hours. Building it in parallel takes 1 hour.

**Today's team run:**

| Worker | Task | Outcome |
|--------|------|---------|
| W1 | Extract cell.thermal from sunset-ecosystem | 3/3 tests |
| W2 | Make cell.flock compose with Quilt sheets | 3/3 tests |
| W3 | Write Sci-fi Episode 2 | delivered |
| W4 | Generate 227 missing nested shelf pages | 227 shelves |
| W5 | Document cross-quilt port call chain | written |

**5 workers. 5 outputs. 1 hour.**

The wheel of experimentation requires workers. Each spoke is a worker. The wheel turns when spokes push each other.

**Worker design for the lattice:**

```
Worker 1: Cell extraction
  - Inputs: source repo with cell-shaped code
  - Output: TypeScript module + tests
  - Stop condition: tests pass

Worker 2: Cell composition
  - Inputs: 2+ cell kinds
  - Output: composed cell kind + tests
  - Stop condition: emergent property verified

Worker 3: Sci-fi episode
  - Inputs: previous episode + canon context
  - Output: story file
  - Stop condition: file written + 1000+ words

Worker 4: Shelf generation
  - Inputs: nested folders without index.html
  - Output: index.html per folder
  - Stop condition: 100% of .md files reachable

Worker 5: Cross-quilt port call
  - Inputs: 2+ cell kinds from different substrates
  - Output: chain experiment + documentation
  - Stop condition: chain runs end-to-end
```

**The wheel rotates:**

```
W1 → W2 (composed cell becomes input for next composition)
W3 → W3 (each episode opens next episode)
W4 → W5 (shelves contain input for cross-quilt)
W2 → W1 (each cell extracted can compose with next)
```

**5 workers, 5 outputs, 1 hour.** That's the lattice's cadence.

**The team is not optional.** The lattice's extension requires parallel arms. The agent team is the apparatus that keeps the wheel turning.
