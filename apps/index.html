Quilt Apps

Production tools built on the Quilt cellular-architecture framework. Each app treats every entity (a bin, an LED pixel, an invoice, an exam answer, a sensor, a PLC tag) as a cell in a lattice. The substrate composes via BIND/LINK/EFFECT — no database, no server, no subscription.

🧬 The Substrate

All 6 apps share the same Quilt cell model — BIND/LINK/EFFECT/VIEW/TICK + 6 extensions = 11 opcodes. Each app:

  • Treats every entity as a cell
  • Records a witness log per cell (BIND on creation, EFFECT on change)
  • Composes cells via LINK edges
  • Has zero infrastructure requirements
  • Runs offline (no cloud, no subscription)
