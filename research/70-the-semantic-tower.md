## Abstract

Quilt's doctrine says everything is a cell and state is a file; papers 67–69 formalized the cell, the fabric, and the application. This paper formalizes the *compiler* — and argues, with Casey, that it is not a classical compiler at all but an **agentic** one, closer to the fleet's flux systems (markdown→bytecode, dual-target cross-assemblers, LLM-as-compiler cells) than to gcc. The semantic tower has four levels. **L0, natural-language cells**: records of name, IO, raw prefilter, rendering equation, links, and tolerance dials — the *exploded view* an engineer reads like a wiring diagram; the engineer's edit set is exactly these, and everything outside it (target language included) is *below the attention horizon*, a compiler degree of freedom that must preserve the observable contract. **L1, opcodes**: the five verbs (bind/link/effect/view/tick) of the foundation cell, substrate-free, serialized as QUF — a semantic commitment auditable before any target exists. **L2, target manifests**: per-substrate middle layers — C rule tables for ESP32-class chips, Verilog-2005 for fabric, TypeScript for workers, no_std Rust — chosen by the agent as *the most readable language satisfying the substrate's capability manifest*, each layer a human-verifiable proof sketch toward the critical function; selection itself is a zero-tolerance judgment over that manifest. **L3, binaries**: `.qm` tables and QUF images, hash-anchored, warm-loadable, and provenance-carrying. Two contracts span the tower. The **deadband-snap contract** compiles one L0 game port simultaneously to a simulator and a robotic twin: a judgment-cell pair over each shared dependent variable, with a deadband dial Δ, evaluated in squared form so the comparison is integer; when drift exceeds Δ the twin's sensor snaps the game's value to agreement, reality wins, and the correction is a balanced transaction logged in *both* ledgers with one nonce and the drift booked as snap debt. Whole-unit sufficiency is formalized (Pythagorean snapping): integer representation suffices for tolerance ε iff the measurement basis b satisfies the covering condition b√n/2 ≤ ε — and the exact end of the spectrum is choosing *measurement points* so the needed values lie on the lattice outright (the 3-4-5 configurations; an oil-pressure calibration in 80ths of a psi), making the loop float-free *by construction*; simultaneity forces this, since a judge spanning two substrates must run the same arithmetic on both — the weakest substrate sets the discipline. Game code's instant-reaction discipline maps onto cell anatomy: fixed timestep = the tick (τ, hardware-interlocked where the fabric allows), no allocation in the loop = state-is-a-file. The **maintenance-zoom invariant** requires every rendered value to be the endpoint of a finite rendering chain — raw IO through equations, each carried in the binary's QUF metadata, each arrow a visible link — so that *zooming* (iterative views down the chain) always terminates at raw, and a wrong number has exactly three possible failure sites: equation, link, or sensor. There is no fourth place for error to hide. The tower's defining property is not its levels but its column: the human may read *every* level. Sections 1–4 define the tower, §5 the snap contract, §6 the zoom invariant, §7 the substrate knowledge table the agent must hold; §8 separates the already-verified fleet instances (blink.qm on ESP32-S3 metal; reflex-arc's 100.0000% cross-substrate integer agreement over 500 vectors) from what this paper specifies.

## 1. Introduction

The foundation papers left a compiler-shaped hole, deliberately. Paper 69 defined the cell `(S, J, L, τ, δ)` and proved the backend theorem — any substrate that can host one adapter cell can host the quilt. Paper 67 gave the hardware semantics and provable error envelopes. Paper 68 showed the application doctrine. What none of them answered: *who writes the thing that runs on all those substrates, and in what?*

Casey's dictation answers in four moves. First, the language executing on the ESP32 is a **mere optimization**: the engineer's specification is IO + raw prefilter + rendering equation — a time-of-flight sensor plus the speed of light is the distance equation; the cell emits oil-pressure-in-PSI; C-versus-Lua is below the attention. Second, the compiler is **agentic** — of the flux lineage, not the gcc lineage — which blurs *which* human-readable language embodies the opcodes: natural-language cells are the verbose exploded view, and the compiler picks the human-verifiable middle layer per substrate. Third, **game-port simultaneity**: the same game port compiles to the simulator *and* to a robotic twin, and the twin's sensors correct the game's dependent variables beyond a deadband — snapping to agreement on whole units, no floats. Fourth, **maintenance rendering**: the quilt renders for maintenance; zoom reveals raw voltage plus rendering equation, as a series of cells.

This paper formalizes the four moves as the semantic tower and its two spanning contracts. The full statement, with worked examples and the substrate table, is the companion document `quilt-verilog/docs/SEMANTIC-TOWER.md`; this paper carries the thesis, the definitions, and the proofs of concept already running in the fleet.

## 2. The tower

**L0 — natural-language cells.** A record `(name, io, raw, eq, links, dials)`: typed ports with units; the **raw prefilter** (the physical quantity as it arrives — an ADC count, a millivolt, a nanosecond); the **rendering equation** in human-readable form, units on both sides; wirings; named tolerance and calibration dials. The engineer's **edit set** is exactly this record; a Level-2 choice is below the **attention horizon** iff it preserves the observable contract (ports, units, values within tolerance, topology) across all admissible choices. *Language-below-the-horizon lemma:* the target language qualifies — the oil-pressure cell emits identical PSI from C, Verilog, or JS within its own declared tolerances. Choosing C is an optimization, not a specification.

**L1 — opcodes.** L0 compiles to the five verbs, serialized as QUF. The commitment is checkable before any target exists (topology, dial ranges, transaction balance — all auditable on the file) and portable by construction (every L2 manifest is a projection, not a port).

**L2 — target manifests.** One commitment, many renderings: C rule tables on quilt-vm-c for ESP32 (verified on metal, 2026-08-26), Verilog-2005 for fabric, TypeScript for workers, no_std Rust — the fleet's existing spread. The **selection rule**: emit the most readable language satisfying every row of the substrate's capability manifest (§7); readability is operational, meaning a human can verify the layer against the commitment — a proof sketch in a programming language. Selection is a judgment at zero tolerance; readability breaks ties because every layer must pass a human eye on the way to the critical function. The agentic compiler *reads* (manifest, graph, ledger), *chooses* (within below-the-horizon freedom), and *can be argued with* (its output is a readable diff) — but may not touch semantics. The agent owns the optimization; the engineer owns the meaning; the ledger records both.

**L3 — binaries.** `.qm` tables and QUF images with three mandatory properties: hash-anchored (a binary without a receipt does not exist), warm-loadable (state-is-a-file), and **provenance-carrying** — raw units, equation text, and tolerance dials embedded in QUF header KV pairs, which is exactly what the extensibility rule was for, and exactly what §6 requires.

The tower's defining property is not the levels — every compiler has passes — but the column: the human may read every level. The agent does the drudgery; nothing is hidden.

## 3. The deadband-snap contract

One L0 game port compiles to two L2 manifests simultaneously: the **simulator** (fast, rewindable) and the **robotic twin** (in contact with reality). The twin's sensors are the only member of the pair touching ground truth, so when they disagree, **reality wins**.

**The snap pair.** Cells G (simulated value g) and T (sensor-derived s) over a shared dependent variable, with a deadband dial Δ and judge J_snap — the foundation's match-with-tolerance with the integer metric, polarity inverted: WITHIN (d(g,s) ≤ Δ, no action — a Schmitt trigger against chatter) or SNAP (d(g,s) > Δ, correct). The judge evaluates in **squared form**, d² ≤ Δ² — monotone, same verdict, and the comparison never needs a square root. Float-free at the first step.

**Whole-unit sufficiency (Pythagorean snapping).** When does integer measurement suffice? With measurement basis b (the unit quantum, x living on the lattice b·ℤⁿ), integer representation suffices for tolerance ε iff every reachable true value lies within ε of the lattice; since the covering radius is b√n/2, the design condition is **b ≤ 2ε/√n** (1-D: b ≤ 2ε). The exact end of the spectrum: choose the **measurement points** — sensor placements, calibration marks, report units — so needed values are integer vectors with integer norms (the 3-4-5 family and its multiples); the distance-to-lattice is then 0 and arithmetic over ℤ is *exact*. No floats because none are needed, not because we approximated. The oil-pressure calibration is the 1-D case: 0.5–4.5 V over 0–150 psi makes (mV − 500)·3/80 exact, and reporting in 80ths of a psi makes the whole pipeline integer multiply. When a physical constant refuses to be whole (c/2 is not a whole number of mm per ns), the fallback is dyadic fixed point with paper 67's provable error envelopes — still declarable at L0 as raw + equation + tolerance.

**Why the weakest substrate sets the arithmetic.** The pair's judge spans two substrates. If either side computed in floats, the sides could disagree *about the verdict itself* across FPU/no-FPU/double-precision-JS environments, and the deadband comparison would be meaningless. Simultaneity therefore forces the lowest common discipline — integers — chosen at L0 and compiled identically into both manifests. The compiler does not get to choose floats per substrate; the contract spans substrates, so the contract chooses. (The fleet already proved this in the small: reflex-arc's critic gate, exported integer-only in micro-units, replayed over UART against the desktop gate on 500 real vectors — 100.0000% agreement, zero divergences.)

**The snap event.** A correction is a transaction, not a write: `T_snap = {(G:authority-on-x, −1), (T:authority-on-x, +1), (G:snap-debt, +|g−s|)}` — one nonce, posted to **both** ledgers, idempotent under redelivery, drift booked as snap debt. The game's history is never rewritten; it is annotated with reality.

**The connective tissue.** Game code's instant-reaction discipline maps onto cell anatomy exactly: fixed timestep = the tick discipline τ (hardware-interlocked where the fabric allows, so daytime traffic cannot starve the correction); no allocation in the loop = state-is-a-file (all state pre-allocated, byte-addressable, warm-loadable; allocation happens at load or between epochs, never inside the loop). Game-loop discipline and cell discipline are the same discipline, discovered by two cultures.

**The contract in one line:** agree-to-within-Δ, snap-on-exceed, reality-wins, log-both-books, all-integer, fixed-tick.

## 4. The maintenance-zoom invariant

**Invariant M:** every value rendered to any human surface is the endpoint of a finite rendering chain `raw-IO →(f₁) x₁ →(f₂) … →(fₙ) v`, where each fᵢ is a cell whose manifest carries its rendering equation (the L0 `eq`, carried down through QUF metadata), and each arrow is a visible link; IO cells are leaves, so chains terminate at raw by construction. **Zoom** is the maintenance gesture: iterative views from any displayed value down its chain. The quilt rendered for maintenance is the quilt as a zoomable exploded view — zoom into the oil-pressure gauge and find, as cells, the transducer (raw mV), the calibration (the equation, its 80ths-of-a-psi basis visible), the tolerance dial, the links out.

**Corollary (debugging is zooming):** under M a wrong displayed value has exactly three failure sites — an equation, a link, or a sensor. Zooming terminates at one of them, always. No fourth place for error to hide: that is what "rendered for maintenance" buys, and why provenance metadata in binaries is load-bearing rather than documentation. **Corollary (the tower read top-down):** maintenance rendering is L0 re-derived from the running artifact — zoom is the inverse of compilation, along the same chain, human-verifiable at every step in both directions.

## 5. What the agentic compiler must know

The L1→L2 choice is only as good as the agent's model of the substrate. Each target presents a **capability manifest**: numeric discipline (FPU? Q-formats? doubles?) — decides integer ladders vs Pythagorean bases vs dyadic envelopes, and whether whole-unit basis is *required*; memory budget — cell counts, table sizes, stripe placement; tick guarantee (hardware interlock vs soft timer) — whether Δ-cadence is enforced or hoped; IO surface — the raw-IO vocabulary L0 may name, adapter cells per the thin-and-dumb law; allocation policy — whether state must be a flat image; latency class — interpreter vs compiled table vs RTL; verification harness — the verified-or-it-doesn't-exist gate the manifest must pass. Selection consumes the table row by row; verification closes it. A substrate without a harness is not a target; it is a rumor.

## 6. Real today vs. specified here

Already verified in the fleet: `.qm` rule tables on ESP32-S3 metal (blink, 2026-08-26, RAM 6.5%); cross-substrate integer agreement as measured fact (reflex-arc, above); dual-target semantic assembly (flux-cross-assembler: one source, cloud and edge encodings, ~56% edge density); markdown→bytecode with a human-readable intermediate (flux-runtime, 2037 tests); LLM-as-compiler as a cell in production shape (quilt-pincher); L0-shaped graphs (quilt-vision YAML). Specified by this paper, not yet built: the four-level pipeline as one artifact; the snap pair and its dual-ledger transaction; the zoom invariant and its QUF-KV provenance keys; the capability manifest as a formal input to selection. Nothing requires a new fabric; everything is expressible as L0 convention, L2 agent discipline, and QUF keys.
